# माजियांग · कोड जेनरेटर (CodeGen) — परियोजना परिचय

> भाषाएँ: [中文](README_ZH.md) · [English](README.md) · [日本語](README_JA.md) · [Português](README_PT.md) · [Español](README_ES.md) · [한국어](README_KO.md) · [Français](README_FR.md) · [Deutsch](README_DE.md) · **हिन्दी** · [العربية](README_AR.md) · [বাংলা](README_BN.md) · [Русский](README_RU.md) · [اردو](README_UR.md)

> **Spring Boot + Vue** के लिए मल्टी-प्रोजेक्ट कोड जेनरेटर: डेटाबेस टेबल संरचनाओं से शुरू होकर, यह **कंपाइल होने योग्य, चलाने योग्य, मेनू-अनुमति सहित** फ्रंट-एंड और बैक-एंड बिज़नेस कोड तैयार करता है, और डिस्क पर लिखने, बैकअप, लेज़र बुककीपिंग तथा रोलबैक का पूरा डिलीवरी लूप संभालता है।

---

GitHub पता: https://github.com/hustxia/CodeGen

## 1. यह क्या है

CodeGen एक "टेबल-आधारित" कोड फैक्ट्री है। आपको बस अपनी बिज़नेस टेबल्स लानी हैं (डेटाबेस इंपोर्ट या DDL पेस्ट करके), फ़ील्ड और जेनरेशन स्विच कॉन्फ़िगर करने हैं, फिर "जेनरेट" पर क्लिक करना है — यह आपके लिए बैक-एंड Entity/Mapper/Service/Controller/DTO/VO, फ्रंट-एंड `api.js` और Vue पेज, मेनू और रूट, यहाँ तक कि A4 प्रिंट पेज और इंटीग्रेशन-टेस्ट स्केलेटन भी जेनरेट कर देता है, और उन्हें सुरक्षित रूप से आपके टारगेट प्रोजेक्ट में लिख देता है।

यह केवल "कोड उगलता" नहीं है — यह **गुणवत्ता गेट और रोलबैक क्षमता वाली एक डिलीवरी पाइपलाइन** है:

```
टेबल इंटेक (DB इंपोर्ट / DDL)
   → फ़ील्ड और स्विच कॉन्फ़िगरेशन (AI सिफ़ारिशों सहित)
      → वन-क्लिक जेनरेशन: सेल्फ-चेक → बैकअप → डिस्क पर लेखन → कंपाइल/सत्यापन → मेनू पंजीकृत करें → रूट पुनर्निर्माण
         → लेज़र बुककीपिंग → रोलबैक-सक्षम
```

## 2. यह कौन-सी समस्याएँ हल करता है

| समस्या (Pain point) | CodeGen का तरीका |
| --- | --- |
| दोहराव वाले CRUD की दीवार — हर टेबल के लिए ढेर सारा बॉयलरप्लेट कोड | प्रति-टेबल स्विच से वन-क्लिक में पूरा फ्रंट और बैक एंड तैयार — CRUD, पेजिनेशन, वैलिडेशन, इंपोर्ट/एक्सपोर्ट सहित |
| फ्रंट/बैक फ़ील्ड और API में बेमेल के कारण बार-बार इंटीग्रेशन सुधार | वही टेबल मेटाडेटा बैक-एंड API और फ्रंट-एंड पेज दोनों को संचालित करता है — शून्य सिमेंटिक विचलन |
| टीम के कन्वेंशन एकरूप करना कठिन; हर किसी की शैली अलग | टेम्प्लेट ही कन्वेंशन हैं: 22 FreeMarker टेम्प्लेट केंद्रीय रूप से प्रबंधित, ऑनलाइन संपादन और संस्करण रोलबैक सहित |
| जेनरेटर "ओवरराइट करते ही खो जाना" — हाथ से लिखा लॉजिक मिट जाता है | मार्कर-ब्लॉक मर्ज तंत्र: हाथ से लिखा कोड सुरक्षित रहता है, केवल जेनरेट किए गए क्षेत्र बदले जाते हैं |
| जेनरेट किया गया कोड कंपाइल समय तक अविश्वसनीय | इन-मेमोरी कंपाइल सेल्फ-चेक (असली `javac`), संरचनात्मक अनुबंध जाँच, डिस्क पर diff पूर्वावलोकन — कंपाइल न हो तो डिस्क पर कुछ नहीं जाता |
| नए सिस्टम को शून्य से स्कैफ़ोल्ड करना समय लेने वाला | पाइपलाइन "एक वाक्य में सिस्टम बनाएँ": DB बनाएँ → स्कैफ़ोल्ड → जेनरेट → पैकेज → मेनू पंजीकृत करें, पूरी तरह स्वचालित |

## 3. क्षमताओं का पूरा परिदृश्य

- **टेबल इंटेक**: DDL पार्सिंग, सीधा डेटाबेस इंपोर्ट, बैच इंटेक विज़ार्ड, स्वतः-प्राप्त कॉलम कॉन्फ़िगरेशन (कंट्रोल / वैलिडेशन / डिक्शनरी / संबंध)।
- **टेबल आकार**: सिंगल टेबल, ट्री टेबल (tree API + ट्री ग्रिड), मास्टर-डिटेल (समान-ट्रांज़ैक्शन सेव + डिटेल टैब), मैनी-टू-मैनी जंक्शन टेबल।
- **जेनरेट किए गए आर्टिफैक्ट**: Entity / Mapper / Service / Controller / DTO / VO + `api.js` + Vue पेज + A4 प्रिंट पेज + इंटीग्रेशन-टेस्ट स्केलेटन।
- **बिज़नेस एन्हांसमेंट**: संबंध ड्रॉपडाउन, डिक्शनरी अनुवाद, डेटा मास्किंग, यूनिकनेस जाँच, फ़ॉर्म लिंकेज, डेटा-स्कोप अनुमतियाँ, Excel इंपोर्ट/एक्सपोर्ट, अप्रूवल वर्कफ़्लो, पेमेंट / फ़ाइल / मोबाइल कैपेबिलिटी पैक।
- **गुणवत्ता गेट**: इन-मेमोरी कंपाइल सेल्फ-चेक (असली `javac`), संरचनात्मक अनुबंध जाँच, अनुमति-संगति जाँच, डिस्क पर diff पूर्वावलोकन, फ्रंट-एंड आर्टिफैक्ट का वास्तविक सत्यापन।
- **सुरक्षित लैंडिंग**: डिस्क पर लेखन + `.gen-backup` बैच बैकअप, हाथ से लिखा कोड सुरक्षित रखने के लिए मार्कर-ब्लॉक मर्ज, `gen_output` चार-स्थिति लेज़र (निर्मित / मर्ज / छोड़ा गया / विफल), ऐतिहासिक रोलबैक।
- **मल्टी-सिस्टम आइसोलेशन**: हर टारगेट प्रोजेक्ट एक "सिस्टम कॉन्फ़िगरेशन" है (फ्रंट/बैक पथ, पैकेज नाम, गेटवे प्रीफ़िक्स, डिपेंडेंसी classpath, जेनरेशन-स्विच डिफ़ॉल्ट) — कई प्रोजेक्ट समानांतर में सेवित।
- **AI एन्हांसमेंट**: एक वाक्य में सिस्टम बनाएँ (AI मॉडलिंग), सीड-डेटा AI एन्हांसमेंट, प्रति-टेबल AI अनुशंसित कॉन्फ़िगरेशन (diff पूर्वावलोकन + चेक करके लागू करें)।

## 4. विशिष्ट परिदृश्य

| परिदृश्य | विवरण |
| --- | --- |
| ट्री टेबल | उत्पाद श्रेणियों जैसा पदानुक्रमित डेटा — स्वतः उत्पादित tree API, ट्री ग्रिड और पैरेंट-चयन ड्रॉपडाउन |
| सिंगल-टेबल CRUD | ग्राहक, उत्पाद आदि — FK ड्रॉपडाउन + डिक्शनरी अनुवाद + इंपोर्ट/एक्सपोर्ट बॉक्स से बाहर उपलब्ध |
| मास्टर-डिटेल | बिक्री ऑर्डर + ऑर्डर आइटम — समान-ट्रांज़ैक्शन सेव, डुअल टैब वाला डिटेल ड्रॉअर (मास्टर जानकारी / विवरण) |
| केवल-पढ़ने योग्य / सांख्यिकी | इन्वेंटरी फ़्लो आदि — लेखन स्विच बंद, केवल क्वेरी और एक्सपोर्ट |
| प्रिंट दस्तावेज़ | "प्रिंट" स्विच चुनें — A4 प्रिंट पेज और रूट बनता है, हेडर + डिटेल टेबल सहित |
| एक वाक्य में सिस्टम बिल्ड | बिज़नेस डोमेन का वर्णन करें — AI एक ही बार में DB और टेबल बनाना + स्कैफ़ोल्ड + पूर्ण जेनरेशन + मेनू पंजीकरण करता है |

> इन सभी परिदृश्यों के चलाने योग्य डेमो (`demo_admin` प्रोजेक्ट) और स्क्रीनशॉट उपलब्ध हैं — देखें `docs/典型场景操作指南-演示后台demo.md` (हिन्दी: चीनी)।

## 5. मुख्य वर्कफ़्लो

```
┌──────────────┐   ┌─────────────────────┐   ┌────────────────────────────────────────────────┐
│ टेबल इंटेक    │ → │ फ़ील्ड/स्विच कॉन्फ़ि.  │ → │ वन-क्लिक जेनरेट (सेल्फ-चेक→बैकअप→डिस्क→      │ → │ लेज़र · रोलबैक │
│              │   │                     │   │ कंपाइल→मेनू→रूट)                              │   │                │
└──────────────┘   └─────────────────────┘   └────────────────────────────────────────────────┘
  DB इंपोर्ट/DDL      कंट्रोल/वैलिडेशन/         सभी गुणवत्ता गेट पास होने पर ही डिस्क पर जाता है;     बैच-स्तरीय ट्रेसेबिलिटी
                     डिक्शनरी                   हाथ से लिखा कोड सुरक्षित रहता है
```

- **Diff पूर्वावलोकन**: जेनरेट किए गए आर्टिफैक्ट की डिस्क की वर्तमान स्थिति से फ़ाइल-दर-फ़ाइल तुलना की जाती है; कुछ भी लिखे जाने से पहले आपकी पुष्टि ली जाती है, जिससे अनजाने ओवरराइट से बचा जाता है।
- **जेनरेशन लेज़र**: हर फ़ाइल अपनी कार्रवाई, बाइट संख्या, MD5 और बैकअप स्थान रिकॉर्ड करती है; पूरा बैच रोलबैक किया जा सकता है।

## 6. एक वाक्य में सिस्टम बनाएँ (Pipeline)

"शून्य से बैक-एंड स्कैफ़ोल्ड करने" के लिए एक उच्च-स्तरीय क्षमता। बिज़नेस डोमेन का वर्णन करने के बाद, पाइपलाइन 5 चरणों से स्वतः आगे बढ़ती है:

| चरण | अर्थ |
| --- | --- |
| `CHECK` | टारगेट प्रोजेक्ट कॉन्फ़िगरेशन और डिपेंडेंसी classpath सत्यापित करें |
| `WRITE` | डेटाबेस और टेबल बनाएँ, स्कैफ़ोल्ड और जेनरेट किए गए आर्टिफैक्ट लिखें |
| `COMPILE` | बैक-एंड `mvn package` / फ्रंट-एंड बिल्ड, इन-मेमोरी कंपाइल सेल्फ-चेक |
| `MENU` | मेनू अनुमतियाँ उत्पन्न और पंजीकृत करें (दोहरा आउटलेट: artifact SQL / internal सीधा लेखन) |
| `ROUTE` | फ्रंट-एंड रूट फ़्रैगमेंट पुनर्निर्माण |

किसी भी चरण की विफलता पर तुरंत पढ़ने योग्य त्रुटि के साथ रुक जाता है, जिससे समस्या का पता लगाना आसान होता है।

## 7. सिस्टम आर्किटेक्चर

फ्रंट-एंड और बैक-एंड अलग, दो रिपॉज़िटरी साथ काम करती हैं:

| रिपॉज़िटरी | भूमिका | स्टैक |
| --- | --- | --- |
| `codegen-server` | बैक-एंड: जेनरेशन इंजन, टेम्प्लेट, वैलिडेशन, लेज़र, पाइपलाइन | Java 21 · Spring Boot 3.2.5 · MyBatis-Plus 3.5.5 · FreeMarker · JWT · MySQL 8 · springdoc-openapi |
| `codegen-web` | फ्रंट-एंड: कंसोल (टेबल कॉन्फ़िग / टेम्प्लेट / लेज़र / सिस्टम प्रबंधन) | Vue 2.7 · Element UI · axios · Vue Router (history मोड) |

बैक-एंड लेयरिंग:

```
controller/    API लेयर (Gen* जेनरेशन चेन / Sys* सिस्टम प्रबंधन / पाइपलाइन)
service/impl/  कोर इंप्लीमेंटेशन (जेनरेशन चेन, टेम्प्लेट इंजन, मर्ज, वैलिडेशन, पाइपलाइन निष्पादन)
util/          टेम्प्लेट इंजन, मॉडल असेंबली, मार्कर-ब्लॉक मर्ज, सेल्फ-चेक कंपाइलेशन
config/        आउटपुट कॉन्फ़िग, सेल्फ-चेक कॉन्फ़िग, टेम्प्लेट सीडर
common/        Result / BaseEntity / अपवाद / ऑडिट
resources/gen-templates/   22 FreeMarker टेम्प्लेट (backend / frontend / shared / test समूह)
```

**वे बेस क्षमताएँ जो टारगेट प्रोजेक्ट में अनिवार्य रूप से होनी चाहिए** (जेनरेटर केवल बिज़नेस कोड बनाता है; बेस की कमी पर चुपचाप विफलता):

1. MyBatis-Plus पेजिनेशन प्लगइन (`PaginationInnerInterceptor`)
2. `Result` / `BaseEntity` / `PageQuery` जैसी बेस क्लासेस (पैकेज प्रीफ़िक्स `root-package` से मेल खाना चाहिए)
3. फ्रंट-एंड `utils/request.js` का `toPageData` (`Page{records,total}` को `{list,total}` में बदलता है)
4. डिपेंडेंसी `springdoc-openapi-starter-webmvc-ui` (जेनरेट किया गया कोड `@Operation` का उपयोग करता है) और `poi-ooxml` (Excel)

## 9. क्विक स्टार्ट

### 1. डेटाबेस बनाएँ (13 प्लेटफ़ॉर्म टेबल + डिफ़ॉल्ट खाता admin/admin123)

```bash
mysql -uroot -p -e "CREATE DATABASE gen_platform DEFAULT CHARSET utf8mb4;"
mysql -uroot -p gen_platform < docs/sql/V1.0__init.sql
```

### 2. टारगेट प्रोजेक्ट कॉन्फ़िगर करें

कॉन्फ़िग टेम्प्लेट कॉपी करें और अपने लोकल पथों के अनुसार समायोजित करें:

```bash
cp src/main/resources/application-local.yml.example src/main/resources/application-local.yml
```

`application-local.yml` को `.gitignore` द्वारा बाहर रखा गया है और यह कमिट नहीं होगा। मुख्य सेटिंग्स:

```yaml
gen:
  output:
    backend-root: /path/to/your-target-project      # आर्टिफैक्ट के डिस्क-लेखन का आधार
    frontend-root: /path/to/your-target-project
    frontend-path: demo-web                          # monorepo के लिए फ्रंट-एंड उपनिर्देशिका
    backend-path: demo-server/src/main/java/com/demo
    package-name: com.demo
    root-package: com.demo                           # आर्टिफैक्ट में बेस-क्लास इंपोर्ट का प्रीफ़िक्स
  selfcheck:
    classpath: /path/to/your-target-project/demo-lib/*
```

सेल्फ-चेक की डिपेंडेंसी निर्देशिका इस प्रकार निर्यात करें:

```bash
cd your-target/demo-server
mvn dependency:copy-dependencies -DoutputDirectory=../demo-lib
```

### 3. बैक-एंड शुरू करें

```bash
mvn package -DskipTests
java -jar target/codegen-server.jar
```

सेवा का डिफ़ॉल्ट पोर्ट **8120** है; API दस्तावेज़ीकरण `/swagger-ui/index.html` पर।

### 4. फ्रंट-एंड शुरू करें

```bash
cd ../codegen-web
npm install
npm run serve
```

फ्रंट-एंड का डिफ़ॉल्ट पोर्ट **9530** है, जो `/dev-api` को बैक-एंड पोर्ट 8120 पर प्रॉक्सी करता है। डिफ़ॉल्ट खाता `admin / admin123`।

### 5. मुख्य कॉन्फ़िगरेशन आइटम

| सेटिंग | विवरण |
| --- | --- |
| `gen.output.*` | आर्टिफैक्ट लेखन पथ, पैकेज नाम, मॉड्यूल मैपिंग |
| `gen.selfcheck.classpath` | इन-मेमोरी कंपाइल सेल्फ-चेक के लिए डिपेंडेंसी classpath, `dir/*` समर्थित |
| `gen.menu.outlet` | `artifact` केवल मेनू SQL और रूट फ़्रैगमेंट बनाता है; `internal` प्लेटफ़ॉर्म की अपनी `sys_menu` में भी लिखता है |
