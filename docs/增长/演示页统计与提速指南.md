## 二、本次改动内容

### 1. 图片：PNG → WebP（原 PNG 全部保留，README 仍引用）

- 工具：Python Pillow 13.0.0，参数 `quality=82, method=6`。
- 8 张 `docs/images/showcase/*.png` 各生成同名 `.webp`，全部低于原体积 42%（远优于"缩到 50% 以下"的目标）。
- 合计：PNG 897,656 B（约 877 KB）→ WebP 340,186 B（约 332 KB），**节省约 62%**。

### 2. `docs/演示效果.html`

- 除首屏第一张（智慧警务 V9.15 数据看板 stage 大图）外，全部 17 个 `<img>` 加 `loading="lazy"`（含灯箱 img，其 src 本为空）。
- 5 处 showcase 缩略图改为 `<picture><source type="image/webp" srcset="...webp"/> + PNG img</picture>` 兜底写法：现代浏览器加载 WebP，旧浏览器回退 PNG。
- **有意不包 stage 大图与灯箱**：页面 JS 会把缩略图路径动态赋给 stage/灯箱的 `img.src`；`<picture>` 的 `<source>` 是静态绑定的，若包住会被固定指向某一张 WebP，切换缩略图时会错图。
- `</body>` 前新增 HTML 注释包裹的 GoatCounter 统计占位（含启用步骤），**未加载任何第三方脚本**。

## 三、如何启用 GoatCounter 统计

1. 到 https://www.goatcounter.com 注册（免费版足够个人项目使用），站点地址形如 `https://XXX.goatcounter.com`，其中 `XXX` 就是站点代码（CODE）。
2. 打开 `docs/演示效果.html`，找到 `</body>` 前的注释块：
   - 把占位里的 `https://CODE.goatcounter.com/count` 中的 `CODE` 替换为第 1 步的站点代码；
   - 删除注释开始标记 `<!--…-->`（即让被包裹的 `<script data-goatcounter=... async src="//gc.zgo.at/count.js"></script>` 恢复生效）。
3. 同步到 GitHub main 后，访问页面并在 goatcounter 后台确认有访问记录即可。
4. GoatCounter 免广告、无 Cookie、轻量（脚本约 2KB），适合开源项目演示页；后台可关闭"公开展示访问数"。

## 五、预期效果（首屏加载）

依据：图片体积对比表（Pillow 13.0.0 实测，quality=82）。

首屏收益分析（原首屏约 9.6s）：

- 首屏可见图仅 1 张（`design/ui/V9.15-看板-运行时验证.png`，未转 WebP，本次未动）；其余 14 张首屏图（隐藏面板 + 缩略图）原会并行抢带宽，现在全部 `loading="lazy"`，浏览器首屏请求从 15 张图降到 1 张。
- 用户切换标签/点击缩略图时按需加载 WebP，单图平均从 112 KB 降到 43 KB，弱网下切换感知从秒级降到数百毫秒。
- 综合估算：首屏关键请求 = HTML（约 22KB）+ 1 张首屏图，排除 14 张图片的带宽竞争后，首屏时间有望从 9.6s 降到 3s 以内（取决于首屏那张看板 PNG 的大小与网络；若需进一步提速，可后续把 `design/ui/` 看板图也转 WebP，本次未包含）。
