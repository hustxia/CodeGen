# 行业范式模板市场 需求

> 版本：v1.0　日期：2026-11-28　对应版本：V1.30 M1.2（V9.22）　提出人：项目owner

## 背景与目标

平台已有 V9.7 行业模板（250+ 套、19 类）与 V9.19 模板市场（导入/导出/删除），但存在三个缺口：

1. **没有行业"范式包"口径**——现有 250+ 套是细粒度模块包（30~45 表），而真实项目需要的是"村务 12 域 61 页""城管 1 事件中心 + 4 监管对象""园区 3 底座 + 55 项""种植 2 底座 + 1 中枢"这种**经过工程化去重、含命中度判断与外接边界**的交付级范式。四套行业方案已在 `WorkBuddy` 工作区沉淀为文档，但平台内没有对应资产。
2. **没有"安装"闭环**——V9.7 的 `POST /gen/ai-build/plan/template` 只生成 plan 预览，不落项目、不留台账；用户装完一个范式后无法回答"这个项目装了哪些包、什么版本、哪些模块"。
3. **前端 V9.19 页面停留在"文件管理"**——只有导入/导出/删除，没有"选包 → 选项目 → 选模块 → 安装"的向导。

**目标**：把四套行业方案变成平台内可检索、可预览、可一键安装到项目的范式包；安装走既有 `planFromTemplate` 收口链路生成 plan（不跳过二次确认），并用安装台账记录版本与模块，让第二步建库有据可依。

**不做**：不自动执行建库 DDL、不生成业务代码——这两步属于流水线 Step2/Step3，必须保留人工确认卡点。

## 功能点

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F-01 | 范式包列表（按行业/分类筛选） | P0 | 四包固定展示：村务/城管/种植/园区，含来源、版本、模块数、表数、命中度、外接系统数 |
| F-02 | 范式包详情（模块清单 + 表清单 + 边界） | P0 | 按 key 取模块与表结构；展示"直建/外接/去重"三类标注与不使用承诺 |
| F-03 | 安装向导：选包 → 选项目 → 选模块 → 确认 | P0 | 复用 `planFromTemplate`，`scope=new/supplement` 两种；只生成 plan，不建库 |
| F-04 | 安装台账：项目已装包列表 | P0 | 按项目查询装了哪些包、版本、模块、安装时间；支持重复安装检测 |
| F-05 | 安装台账详情与移除 | P1 | 查看某次安装的 plan 摘要；移除记录（不删已经生成的 gen_table） |
| F-06 | 四包种子数据（村务/城管/种植/园区） | P0 | 以 JSON 行业包落 `industry-templates/`，以 SQL 落安装台账种子 |
| F-07 | 复用 V9.19 导入/导出/删除 | P1 | 既有端点不重做；范式包同样可被导出/导入（source 标记 builtin） |

## 边界与异常

| 场景 | 期望行为 |
|---|---|
| 项目未选 / 模块未选 | 提示"请选择目标项目""至少选择一个模块"，不生成 plan |
| 同一项目重复安装同一包同版本 | 返回 `code 400`："已安装该范式包 vX，请勿重复安装"；如确需重装先移除台账 |
| `scope=supplement` 但未传 projectId | `code 400`（沿用既有 `planFromTemplate` 校验） |
| 表数与包声明不符 | 安装前校验 `GenTemplatePackValidator` 限额，超限拒绝，不落台账 |
| plan 生成失败（模板 key 不存在/表为空） | 复用既有业务错误码，不写台账（事务回滚） |
| 移除安装记录 | 只删台账，不删 `gen_table`（避免破坏已建库数据）；前端提示二次确认 |
| 预置范式包被删除 | 拒绝（`FORBIDDEN`），与 V9.19 预置包保护一致 |
| 无权限用户访问市场 | 沿用平台 RBAC，前端隐藏入口（本期不改权限体系） |

## 验收标准

- [ ] F-01：`GET /gen/industry-pack/list?category=政务治理` 只返回村务包；四包总数 = 4
- [ ] F-02：`GET /gen/industry-pack/detail/village_affairs` 返回 5 模块 85 表，含直建/外接标注
- [ ] F-03：`POST /gen/industry-pack/install` 对 `village_affairs` + 项目 1 + 全模块，返回 plan（表数 85、source=template），且 `gen_industry_install` 新增 1 行
- [ ] F-04：`GET /gen/industry-pack/installed?projectId=1` 返回刚装的包，版本/模块/时间齐全
- [ ] 边界：同项目同包重复安装返回 `code 400` 且台账行数不变；移除后行数 -1、`gen_table` 行数不变
- [ ] UI：市场页四包卡片、详情抽屉、安装向导三步均可打开，console 零 error
