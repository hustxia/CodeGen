## 一、项目一句话定位

**以表为源的代码工厂**：导入数据库连接或粘贴 DDL，一次生成可编译、可运行、自带菜单权限与国际化全链路的 Spring Boot 3 + Vue 3 + Element Plus 业务系统，并负责写盘、备份、记账、回滚的完整交付闭环。表驱动而非提示词驱动——前后端不会漂移。

体量：约 7.3 万行源码（后端 57.9k / 前端 15.1k），9 种生成模式，48 份多语言 README。

### 2. 生成链路（产物全景）

- **代码产物**：Entity / Mapper / Service / Controller / DTO / VO、前端 api.js 与 Vue 页面、路由、菜单 SQL、A4 打印页、集成测试骨架；树表 / 主子表 / 一主多子级联完整支持。
- **9 种生成模式**：simple / relation / master-detail / master-multichild / multi / micro / flow / pay / file。
- **脚手架基座**：登录、权限、字典、素材、品牌参数化、上传、测试基座等 22+ 基座类。
- **能力包（三态开关，关闭时产物零 diff）**：
  - 支付（微信/支付宝/Mock，V6.3）
  - 工作流双引擎 Activiti/BPMN（V6.1）
  - 移动端 uni-app（V6.5）
  - 文件上传 sys_file（V6.6）
  - 微服务设施 Nacos/Gateway/Feign（V6.0）
  - 产物测试出厂（V6.7）
  - **数据可视化图表 V9.15**：`GenChartDeriver` 从列元数据自动推导图型（趋势/占比/排行），`GenDashboardWriter` 产出看板页 + ChartCard.vue + chartStats.ftl，零领域耦合
- **国际化 V8.0**：生成物整页 i18n，框架支持 **206 种语言**（12 种 RTL）/ **8 种专业精译**（中英日韩法德西阿），双轨制 + 回落链（目标语言→zh-CN→内联中文），**i18n OFF 逐字节零 diff 是 CI 永久卡点**。
- **前端现代化 V9.0**：生成物 Vue 3 + Element Plus + Vite 5（平台控制台仍 Vue 2.7，技术债见规划）。

### 3. 交付闭环（安全写盘）

- 生成前差异预览 + dryRun 影响面；写盘自动备份、生成台账、受保护跳过、`gen:begin-end` 标记块合并保留手写代码、四态账本一键回滚（V4.2/V6.8）。
- 生成自检：占位符残留、Vue/JS 结构、**真实 javac 编译**、字典绑定、实体列契约、权限码一致性（V7.3）。
- SQL 统一交付出口：流水线与手动出口一致，落 `db/init_tables.sql` + `init_seed.sql` + 菜单 SQL（V7.2/V7.3）。
- 一句话建系统 **12 步流水线**：DDL 预览 → 建库 → 生成 → 灌数据 → 全页验收；V9.4 分阶段确认（AI 推荐→编辑→SQL 只读预览→逐阶段门禁，所见即所得）。
- 多流水线并发 + 启动恢复：PipelineRunGate 闸门（全局上限+同系统互斥）、running 孤儿状态启动自愈（V9.8）。
- 部署交付：Dockerfile / compose / CI 模板 / 健康检查。

## 四、版本规划（V9.16 → V10）

> 规划原则：**先降低试用门槛（获客），再补能力深度（留存），最后做生态（护城河）**。当前项目最大的问题不是功能不足而是没人用——外部访客约 0.5 人/天，所以第一个版本优先解决「想试的人 5 分钟内能跑起来」。

### V9.16 — 一键试用与演示体验（P0，增长杠杆最大）

**目标**：把「Maven + MySQL + 手工配库才能跑」的门槛降到 5 分钟。

- [ ] **Docker 一键起**：`docker compose up` 起 codegen-server + MySQL（预灌演示库），README 首屏放命令
- [ ] **H2 内存库 demo 模式**：无外部依赖启动，内置 1 套示例工程数据，适合快速体验
- [ ] **演示页体验闭环**：图片转 WebP + 懒加载（首屏 9.6s → <3s）、GoatCounter/umami 统计接入（曝光可归因）、演示账号直接放首页
- [ ] 生成器自身加「欢迎/快速开始」CLI 引导（复用 V9.15 增长钩子经验）

**验收**：新用户从 clone 到看到生成页面 ≤ 5 分钟；演示页 Lighthouse 性能分 > 85。

### V9.17 — 能力包深度补全（P1，按实战反馈排序）

**目标**：把 P1 backlog 中被真实行业项目点名过的能力补齐，优先服务已验证的五行业场景。

- [ ] 支付：JSAPI/H5、退款、`pay_code` 表级绑定、支付宝沙箱全流程（V6.3）
- [ ] 工作流：流程图渲染、会签/委派、流程设计器（V6.1）
- [ ] 打印：横版、金额大写、`print_title`、条码/二维码（V4.5）
- [ ] 安全：数据权限 UI、限流、密码策略、单用户互踢（V6.4）
- [ ] 唯一性校验 400 断言前后端对齐（V6.7）

**验收**：每项能力包都有对应 ftl 快照测试 + 行业系统实测截图；全量测试保持 0 fail。

### V9.18 — 生成质量与可维护性（P1，工程信心）

**目标**：让模板改动可见、产物回归自动化、验证中心结果成为合并门禁。

- [ ] 模板影响面预览（改模板 → 波及表/产物清单，含 UI 图）
- [ ] 增量保存 child_save_mode、一对一/多对多写回（V4.4）
- [ ] S8/S9 自动化：截图验证 + 新旧 jar diff -r 进入验证中心套件
- [ ] 验证中心结果接 CI 合并门禁；测试中心支持定时执行
- [ ] 平台控制台 Vue 2.7 → Vue 3 + Element Plus（最后一个 Vue 2 阵地）

### V9.19 — 建模规模化收尾（P2）

- [ ] confirm 建库阶段分批化（V9.6 遗留，超大型串行 DDL 会话）
- [ ] 翻译贡献流程自动化（PR 校验 key 覆盖）、精译 8 → 12（ru-RU / pt-BR / id-ID 优先）
- [ ] 模板市场雏形：行业模板支持用户自定义包导入/导出

### V10 — 战略方向（候选，按数据决定）

| 方向       | 说明                                 | 触发条件                           |
| -------- | ---------------------------------- | ------------------------------ |
| 云端生成服务   | SaaS 化：在线建库→生成→下载 ZIP，免本地环境        | V9.16 demo 数据显示真实使用量 > 50 UV/周 |
| 插件化能力包生态 | 能力包（支付/工作流/图表）开放第三方接入规范            | star > 100 且有外部 PR             |
| AI 迭代式生成 | 生成后对话式调整页面/字段（V7.0 曾明确不做，量级大需单独立版） | 核心转化漏斗跑通之后                     |

### 里程碑依赖与风险

- V9.16 不改任何生成模板 → 无回归风险，可立即开工。
- V9.17 各能力包相互独立，可并行；每项必须带快照测试（V8.1 建立的测试网是安全绳）。
- V9.18 控制台 Vue 3 升级是破坏性改动，放最后且需先建控制台侧快照基线。
- 红线约束持续有效：**i18n OFF 逐字节零 diff 契约**、**能力包关闭零 diff 契约**、测试阈值只升不降。
