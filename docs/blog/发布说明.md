## 发布步骤（推荐 HTML 粘贴版）

1. 登录 CSDN → 进入「写博客」页面
2. 用浏览器打开 `智慧村务管理系统实战-CSDN粘贴版.html`
3. 在页面内 `Ctrl+A` 全选 → `Ctrl+C` 复制
4. 粘贴到 CSDN 编辑器正文区
5. 等待图片自动上传（首次可能需十几秒）
6. 补充标题、标签（建议：`代码生成器` `Spring Boot` `Vue` `智慧村务` `低代码` `项目实战`）
7. 设置封面（可用 `images/01-home.png`）→ 发布

> 若图片未自动转存：改用 Markdown 版，在 CSDN Markdown 编辑器里逐张上传 `images/` 下的截图。

## 建议的标题/摘要

- **标题**：从 85 张表到能跑的系统：用自研代码生成器 3 小时搭出智慧村务管理平台
- **摘要**：真实项目完整记录——行业模板→一键生成→菜单规划→演示数据→审批流→首页统计→界面美化，附 9 张实拍截图与 6 个踩坑修法。
