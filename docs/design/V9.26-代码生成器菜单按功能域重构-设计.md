# V9.26 代码生成器菜单按功能域重构 — 设计

## 一、背景与问题

菜单由两段拼接：后端 `/auth/routers` 下发 11 项（`/gen` 目录 7 子项 + `/system` 3 子项 + 监控/测试/验证），前端 `permission.js` 静态注入 11 个平铺入口。侧边栏近 20 项顶层无分组，且：

| 问题 | 实例 |
|---|---|
| 标题重名 | `/gen/project` 与 `/system` 都叫「系统管理」；`/gen/table` 与父目录 `/gen` 都叫「代码生成」 |
| 版本号入标题 | 「V9.5 AI 建表」 |
| 中英混杂 | 「MCP Server」 |
| 无功能分组 | 澄清向导 / 护栏规则 / 规格工件链 / 规格对账 四个 SDD 能力平铺 |
| allPaths 漂移 | 静态路径硬编码仅 6 条，漏 spec / converge / industry-pack 系列 |

## 二、规划原则（按系统功能相关）

按「从需求到交付」链路，把 18 个代码生成器入口归为 5 个功能目录：

1. **项目与数据**：项目管理、数据表管理、文案翻译
2. **规格与质量**（SDD / M2）：澄清向导、护栏规则、规格工件链、规格对账
3. **模板与范式**：代码模板、模板市场、模板影响面、行业范式（范式市场 / 范式安装 / 我的安装）
4. **生成作业**：一句话建系统、AI 智能建表、批量接管、生成台账
5. **集成服务**：MCP 服务

非代码生成器目录（系统管理 / 系统监控 / 测试中心 / 验证中心）保持后端下发结构不变。

## 三、命名规范

| 路径 | 原名 | 新名 |
|---|---|---|
| `/gen/project` | 系统管理 | 项目管理 |
| `/gen/table` | 代码生成 | 数据表管理 |
| `/gen/aibuild` | V9.5 AI 建表 | AI 智能建表 |
| `/gen/mcp` | MCP Server | MCP 服务 |
| `/gen/industry-pack` | 行业范式市场 | 范式市场（归入「行业范式」子目录） |

仅在前端覆盖展示名（`TITLE_OVERRIDES`），不改 `sys_menu` 数据；可选同步脚本见 `V9.26__menu_rename.sql`。

## 四、落地方式

`permission.js` 的 `generateRoutes`：

1. 拆出后端 `/gen` 目录子项，与 11 个静态入口合并成按 path 索引的 Map；
2. 按 `FUNCTION_GROUPS.order` 归类为 5 个 `type=1` 功能目录；后端新增但未登记的 `/gen` 子项保底挂到「项目与数据」，避免菜单丢失；
3. 「行业范式」作为 `type=1` 子目录，`buildRoutes` 自动摊平孙节点为绝对路径路由，`SidebarItem` 递归渲染三级；
4. `allPaths` 改为 `collectPaths(menus)` 自动生成，消除硬编码漂移；
5. 保留隐藏 `/gen` redirect 兼容老书签。

## 五、验证记录（2026-11-28 实机）

- **分组落地**：侧边栏顶层 5 个功能目录（项目与数据 / 规格与质量 / 模板与范式 / 生成作业 / 集成服务），「模板与范式」下「行业范式」为三级目录。截图 `codegen-web/ui-menu-v926.png`（见下方路径）。
- **叶子可达**：CDP 单浏览器逐点走查 18 个叶子路径，`TOTAL=18 PASS=18 FAIL=0`，console / page / 失败请求 / HTTP 4xx 全零。明细 `D:/workspace/tmp-v925/menu-walk-v926.json`。
- **lint**：`npx vue-cli-service lint --no-fix src/store/modules/permission.js` → No lint errors found。
- **改名生效**：走查 title 依次出现「项目管理 / 数据表管理 / 范式市场 / AI 智能建表 / MCP 服务」，无 V9.5 前缀、无中英混杂、无父子重名。
- **副作用检查**：后端未改动；`allPaths` 由菜单树自动收集，历史硬编码 6 条遗漏已消除。

## 六、关联：MCP 菜单 500 报错

点击 MCP 菜单触发 `/gen/mcp/logs` 返回 `code=500`，根因是 `gen_mcp_call_log` 表未建（V9.23 DDL 从未在本地库执行）。执行 `V9.23__mcp_server.sql` 后接口 200、页面零 error。已沉淀坑库。
