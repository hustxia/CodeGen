## 二、主题与目标

**主题：标准 A4 单据打印，生成物零第三方依赖**

一句话：给（主子）表生成一张排版好的 A4 打印页——抬头、主表信息、全部明细表、合计、签名栏——浏览器 `window.print()` 直接打，或"另存为 PDF"，不引入任何打印/PDF 第三方库。

**技术选型理由**：单据版式本质是"文本 + 表格"，纯 CSS `@page` 完全覆盖；pdfmake/jspdf 方案 400KB+ 依赖且中文字体嵌入复杂，浏览器原生打印在 Chrome/Edge 下 A4 精度可靠。生成物保持与现有代码同风格：零运行时新依赖。

## 三、任务清单

### P0-1 printPage.ftl 打印页模板（规模 L，本版核心）

生成 `views/{module}/print.vue`，版式全要素：

```
┌─────────────────────────────┐
│  单据标题（默认=表注释）        │  ← 居中大字
│  单号：{id}   打印时间：…      │  ← 右对齐小字
├─────────────────────────────┤
│  主表信息区：两列键值网格       │  ← 取详情列（isForm）
├─────────────────────────────┤
│  明细一：{子表1注释}            │  ← 每张子表一个块
│  ┌── 表头（跨页自动重复）──┐   │
│  │ … 列 …                │   │
│  └── 合计行（数值列自动Σ）──┘   │
│  明细二：{子表2注释} …          │
├─────────────────────────────┤
│ 制单人____ 审核____ 批准____  │  ← 签名栏
└─────────────────────────────┘
```

关键 CSS（生成进 print.vue 的 scoped 样式）：

- `@page { size: A4 portrait; margin: 14mm 12mm }`
- 明细表头 `thead { display: table-header-group }` —— 跨页自动重复表头
- `tr { break-inside: avoid }` —— 行不被拦腰截断
- `@media print` 隐藏一切非单据元素（按钮/导航）；屏幕预览按 A4 宽度 794px 等比模拟

模型侧：`GenTemplateModel` 给打印页传"打印列集"（子表 `isList` 列 + `isNumeric` 标记，复用 javaType 判定 BigDecimal/Double）。

## 四、自动化验收方式（S8）

纸张尺寸没法在浏览器 JS 里直接断言，用 **Chrome headless `--print-to-pdf`** 打闭环：

1. CDP 打开生成的打印页 → 全页截图（预览版式人工确认）
2. `--print-to-pdf` 输出 PDF → 断言页面尺寸 595×842 pt（A4）、页数随明细分页正确增加
3. 分页表头重复：PDF 第 2 页含明细表头文本（`pdftotext` 或 pdf.js 断言）
4. `verify:all` 三层 PASS

## 八、风险与应对

| 风险 | 应对 |
|---|---|
| 浏览器打印分页差异（Chrome/Edge 微差） | 版式用表格布局不用 flex/float（分页行为最稳定）；验收以 Chrome 为准，Edge 抽查 |
| 打印页脱离导航壳的注册方式与目标工程路由结构冲突 | 路由片段走既有 routerSnippet 追加机制；readme 写明放无 layout 区 |
| 明细列太多横向溢出 A4 | 超过 8 列自动精简到 isList 前列 + 生成时 readme 提示；列宽均分 |
| 合计浮点误差 | BigDecimal 列在 JS 侧按分计算后格式化，或直接字符串拼接服务端算好的合计（倾向后者：/with-children 后端带合计，前端不算数） |
