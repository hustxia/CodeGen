# 代码生成器 V7.3 —— 功能盘点与规划

> 盘点基准：`xyh_dev` 分支 `c623fe0`（2026-11-06），覆盖 V3.1 → V7.2。
> 本文只做现状盘点与下一版建议，不替代各版本规划文档。

## 一、结论

平台已从「模板生成代码」演进为「建库 → 建模 → 生成 → 自检 → 交付 → 能力包」的完整流水线。

- **强项**：生成链路闭环（预览/差异/写盘/下载/自检）；产物零重依赖；多系统、多模块、微服务三态；可维护性（备份/台账/受保护文件/用户区）；质量护栏（自检门禁/基线快照/契约测试）；能力包（支付/工作流/移动端/文件/测试）。
- **短板**：AI 能力只在流水线内、表配置页无入口；手动写盘/下载不产出 SQL 交付物；产物测试不参与自检编译；生成器自身债务（脚手架单类 4779 行）；文档 backlog 中 P1 长尾较多。

## 四、缺口清单

### P0（影响交付可信度）

1. **自检不编译产物测试**：`src/test/java` 只计数不编译（本次修复的取舍），测试类写坏了要等目标工程 `mvn test` 才暴露。
2. **手动出口不交付 SQL**：V7.2 只在流水线成功后复制 SQL；表配置页「写入磁盘」、下载 ZIP 不产出 `db/init_tables.sql`，同一条生成链路两种交付结果。
3. **AI 推荐无表级入口**：V7.0 明确不做表配置页按钮，导致「先有表、后补 AI 建议」只能重跑整条流水线。
4. **生成器自身债务**：`GenScaffoldServiceImpl` 约 4779 行；模板影响面不可见（改了模板不知道波及哪些表/产物）。
5. **提交历史可读性**：`eebff88` 混装自检修复、AI 推荐、V7.2 三类改动，后续应按主题拆提交（不回写历史）。

## 五、V7.3 建议：交付可信度

**主题**：让「流水线生成」和「页面手动生成」产出同一套可信交付物，并把 AI 推荐从流水线内解锁到表级。

| 编号 | 任务 | 要点 |
|---|---|---|
| P0-1 | 自检补产物测试编译 | 单独用产物测试 classpath 编译 `src/test/java`，编译错误按文件/行号报 ERROR；保留本次「不污染主编译」的取舍 |
| P0-2 | 统一 SQL 交付出口 | 抽象「交付物落盘」，写盘/下载/流水线三处共用：`db/init_tables.sql`、`init_seed.sql`、菜单 SQL，覆盖前走备份 |
| P0-3 | 表配置页 AI 推荐入口 | 复用 V7.0 `preview/apply`，选中表即可推荐；未应用不写库，已手改项默认不勾选 |
| P1-1 | 模板影响面预览 | 基于模板 → 表清单 → 产物类型反查，写盘前展示波及面 |
| P1-2 | `smoke.sh` | CLI 交付物冒烟：起服务 → 登录 → 列表接口 200 |

P0-3 的实现取舍：

- **服务端签发 token，产物落 `<logDir>/ai-recommend/<token>.json`**。客户端只拿 diff 视图和 token，
  应用时回传勾选清单——建议值不经客户端，保持 V7.0「客户端传值不可信」的契约。
- **token 正则先行**（`^AIT<projectId>-<yyyyMMddHHmmss>-<8位hex>$`），既做格式校验也是路径穿越防线；
  同系统产物只留最近 5 份，目录不会无限膨胀。
- **表级入口不生成菜单组织建议**：只看一部分表归纳不出可靠分组，`moduleName` 的表级建议已覆盖分组诉求。
- 离线验证用 `scripts/mock-llm.py`（OpenAI 兼容假服务），可复跑「推荐 → 落盘 → diff → 勾选写库」全链路。

**验收（二值）**

- AC-1 故意写坏一个产物测试 → 自检 ERROR 且给出行号；正确产物 → PASS。已验（`GenSelfCheckTestCompileTest`）
- AC-2 表配置页写盘后，目标工程 `db/` 出现 `init_tables.sql`、`init_seed.sql`，内容与流水线产物一致。已验（`GenSqlDeliverServiceTest`）
- AC-3 表配置页可发起 AI 推荐；未点应用时 `gen_table / gen_table_column` 零 UPDATE。已验（端到端：空勾选 apply 返回 0，库值不变）
- AC-4 模板影响面预览列出的表/产物与实际写盘结果一致。未开始（P1-1）
- AC-5 全量测试绿 + WMS 项目（20 张表）实跑自检 `PASSED=true`。全量 227 例绿；WMS 实跑待随下次生成验证

## 七、风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 自检引入测试编译 → 基座缺 test-scope 包 | 满屏假错误 | 产物测试编译只做「语法/符号」级，依赖缺口降级为 WARNING |
| SQL 交付物多出口 | 三处逻辑漂移 | 单一 `SqlDeliverService`，三处只传参数 |
| AI 入口下放到表配置页 | 单表调用频次高、成本上升 | 批量上限沿用 V7.0（每批 ≤10 表），结果缓存到步骤产物 |
| 影响面反查不准 | 用户误判 | 以实际 `preview` 文件清单为真源，模板维度只做索引 |
