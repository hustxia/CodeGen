# A4 打印单据 - 设计文档

> 版本：V4.5 | 起草：2026-10-23 | 需求：`docs/requirements/A4打印单据-需求.md`

## 1. 表结构

```sql
-- V4.5__gen_print.sql（幂等，information_schema 预检）
-- 表级：三态。NULL=跟随系统默认（关）、1=生成打印页、0=强制不生成。
-- 坑库教训（mysql.md）：NOT NULL DEFAULT 会让「表级未配置」状态不存在，
-- 系统默认层永远被表级短路成死配置，故必须 NULL DEFAULT NULL。
ALTER TABLE gen_table ADD COLUMN gen_print TINYINT NULL DEFAULT NULL COMMENT '打印单据:NULL=跟随系统 1=生成 0=不生成';

-- 系统级：NULL=未配置（回落硬编码 0=关）
ALTER TABLE sys_project ADD COLUMN default_gen_print TINYINT NULL DEFAULT NULL COMMENT '打印单据默认:NULL=未配置(关) 1=默认生成 0=默认不生成';
```

无种子数据（开关列，存量行全 NULL 即正确状态）。

## 2. 功能设计

| 编号 | 功能点 | 页面/位置 | 字段与操作 | 状态流转 | 验收标准 |
|---|---|---|---|---|---|
| F-01 | 打印页模板 | 生成物 `src/views/{module}/print.vue` | 抬头（表注释居中）→ 单号+打印时间 → 主表键值区（formColumns 两列网格）→ 每子表明细块（listColumns，>8 列截断）→ 数值合计行 → 签名栏 | 静态页，onMounted 取数 | 含 `@page { size: A4 portrait }`、`thead{display:table-header-group}`、`tr{break-inside:avoid}`、`@media print` 隐藏非单据元素 |
| F-02 | 打印开关链路 | 表配置弹窗 / 系统管理 | 表级「打印单据」三态下拉（从表禁用）+ 系统默认「打印单据默认」三态下拉 | 表级→系统→硬编码 0 | 开关关：无 print.vue、无打印按钮；开：两者都有 |
| F-03 | 打印入口 | 生成物列表页/路由 | 操作列「打印」按钮（opColWidth +62）→ `this.$router.push('/print/{module}/'+id)`；routerSnippet 追加无 layout 顶层路由 | — | 新窗口直达打印页，无侧边栏 |
| F-04 | 质量护栏 | 测试 | 基线 4 场景 × 13 = 52 份；契约 `printPageContainsA4Layout` | — | mvn -o test 全绿 |
| F-05 | readme | ZIP 共享文件 | 记录「含/不含打印页」 | — | 文案与实际产物一致 |

**开关回落唯一实现**：`GenTemplateModel.resolveGenPrint(Integer tableVal, Integer projectVal)` 静态方法（表级非 null 用表级 → 系统非 null 用系统 → false），引擎渲染与 routerSnippet 都走 `build()` 产出的 `genPrint` 键，不出现第二处判定。

**有效开关** = `genFrontend && resolveGenPrint(...) && (hasChild || genDetailApi) && !isChild`。

**打印页取数**：主子表 `get${className}WithChildren(id)`（复用 V4.4 的 `{master, children:[{key,comment,rows}]}`）；单表 `get${className}Detail(id)`。孙表行由前端从 `children[].rows[].{gcVar}s` 展平。

**合计**：BigDecimal/Double 列 `Math.round(v*100)` 累加后 `(sum/100).toFixed(2)`；Integer/Long 直接累加。模板只给 isList 且 javaType ∈ {Integer,Long,BigDecimal,Double} 的列生成合计。

## 3. 接口设计

**无新增后端接口**。打印页复用：

| 接口 | 方法 | 路径 | 请求体 | 响应 |
|---|---|---|---|---|
| 主子表详情 | GET | `/api/{prefix}/{module}/{id}/with-children` | — | `{master, children:[{key,tableName,comment,rows}]}`（V4.4 既有） |
| 单表详情 | GET | `/api/{prefix}/{module}/{id}` | — | `{code,msg,data:VO}`（既有） |

前端产物新增路由（无 layout 顶层）：`{ path: '/print/{module}/:id', name: 'Print{className}', component: print.vue }`。
