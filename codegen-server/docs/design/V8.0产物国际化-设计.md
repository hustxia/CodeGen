## 一、总体设计

```
平台侧                                       产物侧
─────────────────────────────              ─────────────────────────────
sys_project.i18n_enabled ─┐
sys_project.default_language ─┤
sys_project.supported_languages ─┼─> I18nCatalog ──> src/locales/<locale>.json
sys_i18n_message（用户译文）─┘      │              src/locales/index.js
                                    ├─> I18nTextRewriter ─> 生成页 $t('common.*')
i18n/messages/*.json（内置精译）────┘              src/utils/i18n.js
                                                   src/components/LanguageSwitch.vue
```

**三条单一实现原则**（对应坑库 `测试与基线.md:245`）：

1. **语言清单**只有 `LanguageConfig.all()` 一处（V7.5 已交付），V8.0 不另建清单；BCP47 标签沿用 `LanguageConfig.options()` 已去重的集合。
2. **文案映射表**只有 `i18n/keys.json` 一处：既驱动内置词库、平台翻译页的键清单，也驱动渲染后重写器。同一句中文不会在两个文件里各写一遍。
3. **译文回落**只有产物 `i18n.js` 的 `t()` 一处：当前语言 → 默认语言 → key 本身。平台生成占位包时不复制默认值，只写空串。

### 为什么模板零改动

V7.4 建立了「22 个模板源码 / jar / DB 三副本 MD5 全一致」门禁，`src/test/resources/gen-baseline/` 有 13 类场景快照。若直接在 `.ftl` 里把中文改成 `$t(...)`，默认场景（未开 i18n）的产物也会变，全部基线与三副本都要刷，风险远大于收益。

因此采用**渲染后重写**：`GenTemplateEngine.render(...)` 返回 `Map<relPath, content>`，在 `GenCodeServiceImpl` 的两个统一出口对前端文件应用 `I18nTextRewriter`。开关关闭时该方法直接原样返回 → **存量产物逐字节零 diff**；开启时按 `keys.json` 的精确上下文规则替换。骨架文件（Java 字符串拼的布局/登录/首页/main.js）则在生成时按开关走带 `$t` 的分支。

## 二、表结构（S2）

### 2.1 `sys_project` 追加列

```sql
ALTER TABLE `sys_project`
  ADD COLUMN `i18n_enabled` tinyint DEFAULT NULL
  COMMENT '产物国际化开关：NULL/0=关，1=开（V8.0）';
```

可空三态、纯追加，存量系统零 diff。幂等写法见 `docs/sql/V8.0__i18n.sql`（`information_schema.COLUMNS` + `PREPARE`，坑库 `mysql.md` #2：裸 `ADD COLUMN` 重跑必报 1060；**刻意不写 `AFTER`**，坑库 mysql.md V6.5 事故）。

### 2.2 新表 `sys_i18n_message`

```sql
CREATE TABLE IF NOT EXISTS `sys_i18n_message` (
  `id` bigint NOT NULL COMMENT '主键',
  `project_id` bigint NOT NULL COMMENT '所属系统（译文按系统隔离）',
  `locale` varchar(32) NOT NULL COMMENT 'BCP47 语言标签，如 en-US',
  `msg_key` varchar(128) NOT NULL COMMENT '文案键，如 common.add',
  `msg_value` text COMMENT '用户译文；NULL/空串=回落到内置精译或默认语言',
  `create_by` bigint DEFAULT NULL,
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `update_by` bigint DEFAULT NULL,
  `update_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  `deleted` tinyint NOT NULL DEFAULT '0',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_i18n_msg` (`project_id`, `locale`, `msg_key`),
  KEY `idx_i18n_project_locale` (`project_id`, `locale`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='V8.0 用户译文覆盖表';
```

**保存语义**：`INSERT ... ON DUPLICATE KEY UPDATE msg_value=VALUES(msg_value)`（Mapper 注解），不做逻辑删除、不产生 `deleted=1` 行，避免唯一键与 `@TableLogic` 打架（坑库 `mysql.md:337` 同族）。清空译文 = 把 `msg_value` 写成 NULL，回落链自动接管。删系统时物理清理该系统的译文行。

### 2.3 菜单

`sys_menu` 幂等插入「文案翻译」页（`/gen/i18n`，组件 `gen/i18n/index`，父级沿用「系统管理」），幂等写法与 `V3.1__project_menu.sql` 同款。

## 三、功能点设计（S3）

| 编号 | 功能点 | 页面/位置 | 字段与操作 | 状态流转 | 验收标准 |
|---|---|---|---|---|---|
| F-01 | i18n 开关 | 平台「系统管理」编辑弹窗 | `i18nEnabled` 三态下拉；留空=关 | NULL→1→0 可回写 | AC-01 |
| F-02/03 | 内置词库 + 占位包 | `i18n/keys.json`、`i18n/messages/*.json` | 60 键 × 8 精译；其余语言键齐全、值空 | — | AC-03 |
| F-04 | 语言包生成 | 产物 `src/locales/` | 按 `supportedLanguages` 过滤 + 白名单 | 留空→默认+8 精译 | AC-02 |
| F-05 | 运行时 | 产物 `src/utils/i18n.js` | `t/setLocale/getLocale/formatNumber/formatDate` | 切换→重渲染+持久化 | AC-05 |
| F-06 | 文案接线 | `I18nTextRewriter` + 骨架 4 文件 | 精确上下文替换，规则来自 keys.json | 关开关→零 diff | AC-04 |
| F-07 | 切换器 | 产物布局 header | `el-select`，只列启用语言 | 选择→`$setLocale` | AC-06 |
| F-08 | RTL | 产物样式 + `i18n.js` | 逻辑属性 CSS + `<html dir>` 同步 | `ar-SA`→rtl | AC-06 |
| F-09 | 文案翻译页 | 平台 `/gen/i18n` | 系统/语言/关键词、覆盖率、表格编辑、保存/导入/导出/重置 | 保存→upsert | AC-07 |
| F-10 | 译文接口 | `/i18n/*` | 6 个端点，统一响应体 | — | AC-08 |

**表格列（文案翻译页）**：文案键、分类、中文原文、内置译文、当前译文（可编辑）、状态（内置/已覆盖/待补译）、覆盖率进度条。
**按钮**：保存、导出 JSON、导入 JSON、重置所选（恢复内置回落）、刷新。
**校验与异常**：语言非法 → 400；系统不存在 → 404；导入 JSON 缺 `items` 或键不在清单 → 逐条跳过并在响应里报 `skipped`；导入上限 5000 条。

## 五、接口设计（S5）

> 项目约定：接口**无 `/api` 前缀**、统一 `{code,msg,data}`、错误也是 HTTP 200 + `code`、`Long` 主键以字符串下发。以下路径三处（Controller / 前端 api / 菜单路由）同步。

| 接口 | 方法 | 路径 | 请求体 / 参数 | 响应 `data` |
|---|---|---|---|---|
| 可用语言与覆盖率 | GET | `/i18n/locales` | `projectId` | `[{locale,label,nameNative,dir,builtin,translated,total}]` |
| 键清单 | GET | `/i18n/keys` | — | `[{key,category,sourceText}]` |
| 译文分页 | POST | `/i18n/message/page` | `{projectId,locale,keyword,pageNum,pageSize}` | `{records:[{key,category,sourceText,builtinValue,value,overridden}],total}` |
| 批量保存 | POST | `/i18n/message/save` | `{projectId,locale,items:[{key,value}]}` | `{saved}` |
| 导出 | GET | `/i18n/message/export` | `projectId,locale` | `{locale,items:[{key,value}]}` |
| 导入 | POST | `/i18n/message/import` | `{projectId,locale,items,overwrite}` | `{imported,skipped,skippedKeys}` |

分页插件沿用平台既有 `PaginationInnerInterceptor`，不新增配置。

## 六、后端设计要点（S6）

| 类 | 职责 |
|---|---|
| `config/I18nCatalog` | 读 `i18n/keys.json` + `i18n/messages/*.json`；提供键清单、内置译文、8 个精译 locale、按标签组装完整语言包（缺值写空串）；资源缺失/损坏降级为空词库并 WARN，不阻断启动（V7.5 `LanguageConfig` 同款） |
| `service/I18nTextRewriter` | 渲染后重写：`rewrite(Map<String,String> files, boolean enabled)`；只对 `.vue` / `.js` 前端文件生效；规则由 `keys.json` 的 `rewrite` 段驱动；统计命中数供自检 |
| `entity/SysI18nMessage` | 译文表实体 |
| `mapper/SysI18nMessageMapper` | upsert 注解 + 按系统/语言查询 |
| `controller/I18nController` | 6 端点，参数校验（locale 正则 + 清单内） |
| `service/I18nMessageService` | 分页/保存/导出/导入/覆盖率，`projectId` 存在性校验 |
| `util/GenTemplateModel` | `resolveI18n` 唯一实现；`ProjectConfig` 加第 13 组件 `Integer i18nEnabled`，**保留 11/12 参兼容构造**（V7.5 教训：不加会让基线测试全挂） |
| `service/impl/GenScaffoldServiceImpl` | 按开关写产物运行时 + 语言包 + 切换器；`frontendMainJs/frontendLayoutVue/frontendLoginVue/frontendHomeVue/frontendRequestJs` 增加带开关的重载，默认重载保持旧签名与旧内容 |
| `service/impl/GenCodeServiceImpl` | 两个渲染出口统一套 `I18nTextRewriter` |

**写盘安全**（坑库 V6.8 / 铁律 6）：新增文件走既有 `write(...)`（受保护清单 / 备份 / 台账三件套），不另写文件流；语言包文件名由白名单标签生成，`^[A-Za-z0-9-]{2,32}$` 先验，防路径穿越。

## 七、前端设计要点（S7）

- 平台：`src/api/i18n.js`、`src/views/gen/i18n/index.vue`、路由 + 菜单；系统编辑弹窗加 `i18nEnabled` 三态下拉（与 `fileEnabled` 同款 `switchDefaults` 处理）。
- 产物：`src/utils/i18n.js` 零依赖；`Vue.prototype.$t` 依赖 Vue 2 的响应式 `Vue.observable` 驱动重渲染；`LanguageSwitch.vue` 通过 `$setLocale` 切换；`el-select` 的选项来自 `src/locales/index.js` 的 `available`。
- 字段绑定：`i18n/locales` 返回的 `label/nameNative/dir/translated/total` 逐字段对齐后端 VO；状态列三态（内置 / 已覆盖 / 待补译）穷举，不漏英文原文。
