# V6.4 权限安全基线 —— 设计文档

> 日期：2026-10-27　上游规划：docs/代码生成器-V6.4-规划.md（P0 全量，P1 缓行）
> 定位：产物安全从「能挡陌生人」升级到「权限闭环 + 密码学合格 + 登录设防」。

## 一、现状与欠账（同规划第一节）

- TokenStore 内存 ConcurrentHashMap，重启全员掉线（10-24 真实工单）
- SHA-256 无盐，脚手架注释自认欠账
- AuthContextFilter 只验登录；前端 v-hasPermi 藏按钮，后端裸奔
- 无验证码 / 失败锁定 / 登录日志；产物连 sys_role/sys_menu 体系表都没有（V3.0 菜单注册脚本假设目标工程已存在）

## 二、P0 实施设计

### P0-1 Token 持久化（重启不掉线）

- 新表 `sys_session`（token/username/login_ip/login_time/expire_time/deleted，进 init_sys_user.sql）
- TokenStore 双层：签发写库 + 内存缓存（TTL 60s），校验 miss 回源查库；校验命中即滑动续期（yml `auth.session-hours`，默认 24h）
- 惰性清理：create() 时距上次清理超 1h 则删除过期行（不引入 @EnableScheduling）
- 登出删行删缓存；单用户多端在线允许

### P0-2 BCrypt 无感迁移

- pom 增 `spring-security-crypto`（单模块，不引全家桶）
- `sys_user.password` varchar(72) + `password_algo`（sha256/bcrypt）；种子 admin 直接 BCrypt 预生成值
- 登录按 algo 分派：旧 sha256 命中 → 立即 BCrypt 重哈希写回 + algo=bcrypt；全量用户自然登录中完成迁移

### P0-3 接口权限点后端强制

- 表基座补齐：`sys_role` / `sys_user_role` / `sys_menu` / `sys_role_menu`（V3.0 菜单注册 SQL 的字段口径），种子 admin 角色直通
- 新接口 `ApiPermContributor`（端点→perms 映射，key="METHOD /path"，支持 `{id}` 段通配）；`PermissionChecker` 汇集全部贡献者 + 加载用户 perms（60s 缓存）+ admin 直通
- AuthContextFilter 两级：登录校验（现状）→ 权限点校验；无权 403「无该操作权限」
- 缺省策略（fail-closed）：映射缺失时 GET 放行、写方法拒绝；映射值空串 = 仅登录（基座能力豁免，如 /flow/**、/pay/**）
- perms 匹配支持 `前缀:*` 与 `*:*:*` 通配（与 V3.0 五级回落同源）
- 生成侧：写盘/ZIP 时按表产出 `{Class}ApiPerms.java`（pkg/common/auth/），端点映射从 gen 配置推导：page/tree/options/export/detail→`:list`，add/import→`:add`，edit→`:edit`，delete→`:remove`

### P0-4 登录防护三件套

- **验证码**：GET /auth/captcha 算术题，BufferedImage 现画 + Base64 PNG，内存 Map 存答案 60s 一次性；前端登录页带验证码输入
- **失败锁定**：sys_user 增 `fail_count`/`lock_until`，5 次锁 10 分钟（落库防重启清零），成功清零
- **登录日志**：`sys_login_log` 表 + `/loginLog/page` 只读接口（复用 IpRegionResolver 归属地）；前端管理页 P1

## 三、前端配套

- login.vue：验证码输入 + 图片点击刷新
- main.js：注册 `v-hasPermi` 指令（读 localStorage.perms）；登录响应带 perms 数组落地

## 四、验收标准（S8 回填）

1. 产物重启 → 原 token 仍有效，业务接口正常响应（不掉线）
2. 旧 SHA-256 用户登录成功且 password 变 BCrypt、algo=bcrypt；新种子用户即 BCrypt
3. 非 admin 用户无 remove 权限调 DELETE → 403；授予后通过；admin 直通
4. 错密码 5 次 → 第 6 次明确提示锁定，10 分钟自动解锁；sys_login_log 全程留痕
5. 平台全量测试绿；产物基线按新产物更新一次

## 五、验证记录（S8 回填）

- 第 1 层 编译：mvn test 166 例全绿（新增 GenV64SecurityBaselineTest 12 断言）；产物 v63pay-server 离线编译通过（spring-security-crypto 走 BOM，中央仓库直供）
- 第 2 层 端到端：v64-s8-smoke.mjs Part-A 41 断言全过——TokenStore 双层落库、BCrypt 分派+种子预生成、PermissionChecker fail-closed、四张权限表+password_algo 种子、验证码端点、失败锁定字段、登录页验证码输入、v-hasPermi 指令、ZIP 注入 DemoFeeApiPerms（:list/:remove 分派正确）、pay 能力包零回归
- 第 3 层 运行时安全链路（v63pay 产物实测）：
  - AC1 重启不掉线：token 签发后跨 4 次进程重启仍有效（sys_session 回源 + 滑动续期）
  - AC2 BCrypt 无感迁移：SHA-256 存量用户登录成功，库内 password 立即变 $2a$10$、algo=bcrypt
  - AC3 接口权限强制：仅 :list 角色的用户 GET 详情 200、DELETE/POST 403「无该操作权限」、支付记录（基座豁免）200、admin 直通 200；无映射写接口 fail-closed 拒绝
  - AC4 登录防护：无验证码登录直接 400；连续 5 次错密码触发锁定并落库（lock_until 持久化，重启不清零），锁定期间正确密码同样被拒；sys_login_log 全程留痕（含失败原因）
- 实测修掉的坑：#45 生成器 captcha() 中 Map.Entry 误调 e.value()（编译期炸）；#46 expire_time/lock_until 强转 Timestamp（MySQL 8 驱动返回 LocalDateTime，运行期 ClassCastException）；#47 loadPerms 查 rm.perms 但 sys_role_menu 无此列（perms 应经 sys_menu 三表联查）；#48 sys_oper_log 不在任何种子（新库调业务接口即 500）。均已修真源 + 基线测试断言防回归
