## 二、功能设计（相对规划的收敛）

| 编号 | 功能点 | 实施要点 |
|---|---|---|
| F-C1 | CLI 生成 | **后端零新增接口**：`codegen.mjs` 直接消费 `/auth/login`（拿 token）→ `POST /gen/table/page`（projectId 查表清单，返回 Long id 序列化为字符串）→ `POST /gen/download`（ZIP 通道）→ 本地解压写盘。CLI 形态：单文件零依赖（Node 18+ 内置 fetch），exit code 0/1/2 对齐 verify-all.mjs |
| F-C2 | 部署物 | `default_gen_deploy` 可空三态（回落唯一实现 `GenTemplateModel.resolveGenDeploy`，沿用 print 先例）；开启时 scaffold 追加 `Dockerfile`（ARG 参数化基础镜像、非 root）、`.dockerignore`、`docker-compose.yml`（app+mysql，健康检查；micro 注释态含 gateway/nacos）、`deploy/ci-github-actions.yml.example`、`deploy/Jenkinsfile.example` |
| F-C3 | 配置安全 | `applicationYml` 的 url/username/password 改 `${DB_URL:...}` 占位符，默认值=原明文值（本机直跑零变化）；local.yml.example 补双通道说明 |

明确不做（同规划 P2）：Helm、Testcontainers、平台可观测性、CLI 写库。

无新增平台接口（CLI 复用既有三个端点，见 F-C1）。

## 四、验证记录（S8 回填，2026-10-25）

- 第 1 层 编译：`mvn -o test` 153 例全绿（ZIP 修复后回归）。
- 第 2 层 接口/CLI：冒烟 `v62-s8-smoke.mjs` **15 断言全 PASS**——CLI status 输出台账、CLI gen 解压写盘 13 文件（src/api 存在）、不存在系统 exit=2、genDeploy 开启后 scaffold 产出 Dockerfile/.dockerignore/docker-compose.yml/两个 CI example、compose 密码走 `${DB_PASSWORD:-root}` 且含 service_healthy、application.yml 密码/URL 占位符且无明文密码行。
- 第 3 层 配置安全 grep：冒烟内置 `/^    password: [^$]/m` 断言（yml 无明文密码行）通过。
- 验证中修复的真 bug：
  1. **CLI 登录后 401**：`login()` 返回整个 `body.data` 而非 `data.token`，`Bearer [object Object]`；
  2. **`/project/page` 不支持 POST**：CLI 改走 `GET /project/list` 全量+本地过滤；
  3. **`/gen/download` 返回截断 ZIP（无 central directory/EOCD）**：`generateZip` 在 try-with-resources 块内 `return bos.toByteArray()`，求值先于 `close()` 写 EOCD——**V5.0 起潜伏，浏览器下载同样受害，V6.2 CLI 首次暴露**。修复：`files` 在块内构建、`toByteArray()` 移到块外。
- 环境坑（已记坑库）：`.jdks` 下全部 JDK 缺 `lib/modules`（temurin-21 裸 `-version` 即 Failed setting boot class path），改用 `D:\tool\jdk-21.0.12.1+1`；会话环境 `HTTP_PROXY`/`http_proxy` 大小写重复导致 PowerShell `Start-Process` 抛「字典中的关键字」——改 Bash 后台启动。
