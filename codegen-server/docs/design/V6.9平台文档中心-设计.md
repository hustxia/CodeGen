## 二、表结构

见 `docs/sql/V6.9__sys_doc.sql`。要点：

- 主键 `bigint`，**雪花**（`BaseEntity` 是 `IdType.ASSIGN_ID`；全局 `id-type: auto` 只影响未标注的实体）
- `create_by/update_by` 为 `bigint`，与 `BaseEntity`（`Long`）对齐；**不用 `varchar`**（V6.6 产物侧 `sys_file` 用 varchar 是因为产物基座没有审计填充器，两边约定不同）
- `ext` 单独成列（不带点、小写），供列表筛选与预览分派，避免每次从 `relative_path` 再解析
- `md5` 预留（当前不做去重）

## 三、配置项（application.yml 新增）

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 30MB        # 单文件
      max-request-size: 35MB     # 整个请求（多层表单/额外字段留余量）

doc:
  upload-dir: ${DOC_UPLOAD_DIR:./uploads/doc}
  max-size-mb: 30
  allowed-exts: ${DOC_ALLOWED_EXTS:pdf,doc,docx,xls,xlsx,ppt,pptx}
  preview:
    enabled: ${DOC_PREVIEW_ENABLED:true}
    engine: ${DOC_PREVIEW_ENGINE:auto}     # auto | browser | libreoffice
    soffice-path: ${DOC_SOFFICE_PATH:}     # 空=查 PATH
    cache-dir: ${DOC_PREVIEW_CACHE_DIR:}   # 空=upload-dir/.preview
    timeout-seconds: 60
    max-concurrency: 2
```

## 四、功能设计

| 编号 | 功能点 | 位置 | 关键实现 | 验收 |
|---|---|---|---|---|
| F-01 | 上传 | `DocController#upload` → `DocService#store` | 校验 `ext`（白名单，不带点小写）→ 校验大小（`doc.max-size-mb`）→ `{yyyyMM}/{uuid}.{ext}` 落盘 → 插 `sys_doc`；`original_name` 截断 255 字符 | AC1/AC2 |
| F-02 | 列表 | `POST /doc/page` | `name` 模糊、`ext` 精确、`previewMode` 计算后随行返回；`pageNum≥1`、`pageSize∈[1,100]` 钳位 | AC3 |
| F-03 | 下载 | `GET /doc/download/{id}` | 查库 → 校验存在 → `ResourceRegion` 流式；`Content-Disposition: attachment; filename*=UTF-8''...` | AC4 |
| F-04 | 删除 | `DELETE /doc/{id}` | 逻辑删；查不到返回 404 业务码；物理文件保留 | AC7 |
| F-05 | PDF 预览 | `GET /doc/preview/{id}` + `PdfViewer.vue` | 原件 PDF → 直接流 `inline`；非 PDF → 引擎转换后流 PDF | AC5 |
| F-06 | Word 预览 | `DocxViewer.vue` / 转换链 | 按回落表分派 | AC6/AC8 |
| F-07 | 能力探测 | `GET /doc/meta/{id}` | 返回 `{previewMode, engine, convertible}` | AC6 |
| F-08 | 权限 | `DocController` 内 `requirePerm("doc:xxx")` | `PermissionService.permissionsOf(userId)` + 超管直通；新增 `ResultCode.FORBIDDEN(403)` | AC7 |
| F-09 | 菜单/路由 | `V6.9__doc_menu.sql` | 菜单驱动路由，`component=doc/index` | AC1 |
| F-10 | 降级 | 前端 + `doc.preview.enabled` | 关 → 按钮变下载；`.doc` 无引擎 → 提示下载 | AC8/AC9 |
| F-11 | 启动自检 | `DocStorageService#afterPropertiesSet` | 打 INFO：上传目录、缓存目录可写、引擎、soffice 版本；探测失败 WARN | AC9 |

### 预览引擎回落表（唯一实现：`DocPreviewEngine#modeOf`）

| engine 配置 | soffice 探测 | PDF | DOCX | DOC | XLS/XLSX/PPT/PPTX |
|---|---|---|---|---|---|
| `auto` | 有 | `pdf` | `pdf`（转） | `pdf`（转） | `pdf`（转） |
| `auto` | 无 | `pdf` | `browser-docx` | `download-only` | `download-only` |
| `browser` | 忽略 | `pdf` | `browser-docx` | `download-only` | `download-only` |
| `libreoffice` | 有 | `pdf` | `pdf`（转） | `pdf`（转） | `pdf`（转） |
| `libreoffice` | 无 | `pdf` | **接口报错 400** | **接口报错 400** | **接口报错 400** |

### 转换与缓存

- 命令：`soffice --headless --norestore -env:UserInstallation=file:///{tempProfile} --convert-to pdf --outdir {outDir} {src}`
- 每次转换独立临时 profile（`%TEMP%/doc-preview/{uuid}`），结束删除——规避 LO 单实例锁
- `Semaphore(2)` 限并发；`Process.waitFor(60s)` 超时则 `destroyForcibly`
- 缓存键：`{cache}/{id}-{fileSize}-{mtime}.pdf`；命中直接返回。`sys_doc` 行不可变（重传=新行），无需失效
- 转换失败 → `Result.fail(400, "文档转换失败：...")`，前端提示后可切浏览器引擎

## 五、接口设计

| 接口 | 方法 | 请求 | 响应 |
|---|---|---|---|
| `/doc/upload` | POST | multipart `file` | `Result<DocVO>`（`id` 字符串 / `originalName` / `ext` / `fileSize` / `previewMode`） |
| `/doc/page` | POST | `{pageNum,pageSize,name,ext}` | `Result<Page<DocVO>>`（`records/total`） |
| `/doc/meta/{id}` | GET | — | `Result<DocMetaVO>`（`previewMode` / `engine` / `convertible`） |
| `/doc/preview/{id}` | GET | — | 二进制 `application/pdf` `inline`（认证） |
| `/doc/raw/{id}` | GET | — | 二进制 `inline`（认证，供 docx-preview 取原件） |
| `/doc/download/{id}` | GET | — | 二进制 `attachment`，原始中文名 |
| `/doc/{id}` | DELETE | — | `Result<Void>`；不存在 `404` 业务码 |

统一约定：HTTP 恒 200，业务码在 `body.code`；二进制端点例外（返回流或 4xx HTTP）。`id` 一律字符串。

权限：`upload→doc:upload`、`page→doc:list`、`delete→doc:remove`、`preview/raw/download/meta→doc:list`（能看列表即可看内容，避免「看得见条目点不开」）。

## 六、前端结构

```
src/api/doc.js                 uploadDoc / pageDoc / docMeta / deleteDoc / downloadUrl
src/views/doc/index.vue        列表 + 上传 + 行操作 + 预览弹窗宿主
src/components/DocPreviewDialog.vue   按 previewMode 分派，含降级提示
src/components/PdfViewer.vue   pdfjs-dist 2.16.105 legacy，canvas 渲染 + 工具栏
src/components/DocxViewer.vue  docx-preview 动态 import，容器渲染
```

- 两个预览器全部 `() => import()` 异步加载（AC10 包体约束）
- 取流：`request({url, method:'get', responseType:'arraybuffer'})`，带 Authorization
- pdf.js worker：`pdfjs-dist@2.16.105` 的 `es5/build/pdf.worker.min.js` 用 `file-loader`/`require` 静态引入，配置 `GlobalWorkerOptions.workerSrc`

## 七、安全设计

1. **不注册** `/uploads/**` 静态映射；所有访问经 `DocController` 校验 token
2. 读文件：`base.resolve(relativePath).normalize()` 后 `startsWith(base)` 双保险；`relativePath` 只由服务端生成
3. 白名单不含 `svg/html/md/js`；`ext` 只从**原始文件名**取（不信任 `Content-Type`）
4. 响应头：`X-Content-Type-Options: nosniff`；预览 `Content-Disposition: inline`，下载 `attachment`
5. 前端禁止 iframe + `?token=`；统一 arraybuffer
6. `soffice` 用 `--norestore` + 独立临时 profile，转换超时可强杀（不执行宏）
