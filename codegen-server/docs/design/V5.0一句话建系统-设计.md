# V5.0「一句话建系统」设计文档（M1 范围）

> 日期：2026-10-24　需求文档：`docs/requirements/V5.0一句话建系统-需求.md`
> 沿用约定：统一响应 200+body.code；Long 序列化字符串；分页 POST /page；路径回落走 GenPathResolver；子进程启动显式 --server.port + 清理 SERVER__PORT

## 一、表结构

```sql
-- 流水线任务头：一次「一句话建系统」对应一行
CREATE TABLE gen_pipeline (
  id             BIGINT       NOT NULL COMMENT '雪花ID',
  pipeline_no    VARCHAR(32)  NOT NULL COMMENT '流水线号 PPL+时间戳',
  project_id     BIGINT       NULL COMMENT '关联 sys_project（建模确认后创建/回填）',
  system_name    VARCHAR(64)  NOT NULL COMMENT '录入的系统名称',
  system_desc    VARCHAR(512) NULL COMMENT '一句话业务描述（喂给 AI）',
  db_name        VARCHAR(64)  NOT NULL COMMENT '目标数据库名',
  backend_port   INT          NULL COMMENT '后端端口（分配器回填）',
  frontend_port  INT          NULL COMMENT '前端端口（分配器回填）',
  mode           VARCHAR(16)  NOT NULL DEFAULT 'ai' COMMENT 'ai=AI建模 manual=手动粘贴DDL',
  status         VARCHAR(16)  NOT NULL DEFAULT 'draft' COMMENT 'draft建模中/await_confirm待确认/running运行中/success成功/failed失败/stopped停止',
  current_step   VARCHAR(32)  NULL COMMENT '当前执行到的步骤 key',
  fail_reason    VARCHAR(1024) NULL COMMENT '失败原因摘要',
  frontend_url   VARCHAR(256) NULL COMMENT '部署完成的前端访问地址',
  backend_pid    BIGINT       NULL COMMENT '后端子进程 PID',
  frontend_pid   BIGINT       NULL COMMENT '前端子进程 PID',
  deleted        TINYINT      NOT NULL DEFAULT 0,
  create_by      BIGINT NULL, create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  update_by      BIGINT NULL, update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id), UNIQUE KEY uk_no (pipeline_no), KEY idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='V5.0 一句话建系统流水线';

-- 流水线步骤明细：一步一行，按 step_order 排序
CREATE TABLE gen_pipeline_step (
  id             BIGINT       NOT NULL COMMENT '雪花ID',
  pipeline_id    BIGINT       NOT NULL COMMENT 'gen_pipeline.id',
  step_key       VARCHAR(32)  NOT NULL COMMENT '步骤key：model/confirm/db/scaffold/gen/package_backend/package_frontend/deploy/health',
  step_name      VARCHAR(64)  NOT NULL COMMENT '步骤中文名',
  step_order     INT          NOT NULL COMMENT '执行顺序',
  side           VARCHAR(16)  NOT NULL DEFAULT 'pipeline' COMMENT 'pipeline/backend/frontend（双进度条分组用）',
  status         VARCHAR(16)  NOT NULL DEFAULT 'pending' COMMENT 'pending/running/success/failed/skipped',
  message        VARCHAR(1024) NULL COMMENT '结果/错误摘要',
  log_excerpt    TEXT         NULL COMMENT '日志摘要（尾部 N 行）',
  started_at     DATETIME NULL, finished_at DATETIME NULL,
  deleted        TINYINT      NOT NULL DEFAULT 0,
  create_by      BIGINT NULL, create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  update_by      BIGINT NULL, update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id), UNIQUE KEY uk_pipe_step (pipeline_id, step_key), KEY idx_pipeline (pipeline_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='V5.0 流水线步骤明细';
```

## 二、功能设计（S3）

| 编号 | 功能点 | 页面/位置 | 字段与操作 | 状态流转 | 验收标准 |
|---|---|---|---|---|---|
| F-01 | AI 领域建模 | 代码生成/建系统向导 第1步 | 输入 systemName/systemDesc；按钮「AI 生成表结构」；mode=manual 时粘贴 DDL 文本域 | draft→建模完成（前端暂存） | AC1；超时 30s 报错可重试 |
| F-02 | 表结构确认 | 第2步 | 表名/注释/列清单（列名/类型/注释/主键）可编辑，可增删表和列；「建库建表」按钮 | — | 编辑结果透传 execute-ddl；AC 依赖 AC1 |
| F-03 | 建库建表+导表 | 第2步确认后 | 二次确认弹窗列明库名与表数 | await_confirm→建库→台账就绪 | 表导入 gen_table 且 project_id 挂新系统 |
| F-04 | 一键流水线 | 第3步 | 「开始构建」；后端按 step_key 串行执行；步骤失败即停 | running→success/failed | 刷新不丢状态（AC4） |
| F-05 | 进度可视化 | 第3步 | el-steps 分组双轨（backend/frontend 并行段）+ 每步耗时/日志摘要；SSE `/gen/pipeline/{id}/stream` | pending→running→success/failed | 推送延迟 <2s |
| F-06 | 部署产物管理 | 第3步完成卡片 | 前端地址按钮「打开系统」；「停止」杀双进程并置 stopped | success↔stopped | AC2/AC3 |
| F-07 | 登录接口补全 | 脚手架模板 | AuthController(POST /auth/login、/auth/logout、GET /auth/me) + 前端登录页 + seed sys_user(admin) | — | AC6 |
| F-08 | 生成前置 lint | 流水线 gen 步骤前 | 检查目标库每表列 vs BaseEntity 约定(id/create_time/update_time/create_by/update_by/deleted)；缺→failed 附补齐 SQL | — | AC5 |
| F-09 | apiBase 去回落 | GenTemplateModel | 删 "demo" 硬编码回落，空前缀时 apiBase=/api/{module} | — | AC8 |

## 三、接口设计（S5）

| 接口 | 方法 | 路径 | 请求体 | 响应 |
|---|---|---|---|---|
| AI 建模 | POST | /gen/pipeline/ai-model | {systemName, systemDesc} | {tables:[{tableName,comment,columns:[{name,type,comment,pk}]}]} |
| 建任务 | POST | /gen/pipeline | {systemName,systemDesc,dbName,mode,ddlText?} | GenPipelineVO（含初始 steps） |
| 执行建库 | POST | /gen/pipeline/{id}/prepare-db | — | {dbName, tableCount} |
| 启动流水线 | POST | /gen/pipeline/{id}/run | {skipConfirm?:bool} | GenPipelineVO |
| 任务详情 | GET | /gen/pipeline/{id} | — | GenPipelineVO（头+steps） |
| 任务分页 | POST | /gen/pipeline/page | {pageNum,pageSize,status?} | records/total |
| 进度推送 | GET(SSE) | /gen/pipeline/{id}/stream | — | text/event-stream：每步状态变更推 GenPipelineVO |
| 停止 | POST | /gen/pipeline/{id}/stop | — | GenPipelineVO |
| lint 预检 | POST | /gen/pipeline/lint-db | {dbName} | {ok, items:[{table,missingCols,fixSql}]} |

VO 约定：id/时间戳/Long 全部字符串化；status/step status 枚举穷举见 F-05。
