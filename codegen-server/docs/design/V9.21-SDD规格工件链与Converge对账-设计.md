## 1. 总体设计

```
gen_spec_artifact（工件版本链）        gen_table / gen_table_column（实际产物）
  CONSTITUTION → SPEC → PLAN →                    │
  TABLES → TASKS                                  │ 采集
        │ 保存即快照(DRAFT)                        │
        │ confirm → CONFIRMED                     │
        └────── structured_json ──→ GenConvergeService（表/字段/枚举三类比对）
                                            ↓
                          gen_converge_report（汇总）+ gen_converge_item（明细）
```

- **工件双存**：`content_md` 给人/Agent 共读，`structured_json` 机器比对——只存 Markdown 没法做集合比对，只存 JSON 没法人工评审。
- **对账三类**：TABLE（表级，全量含 EXTRA）、FIELD（`表名.列名` 键，不做全量）、ENUM（字典编码，不做全量）。
- 人工卡点：SPEC 必须 CONFIRMED 才能对账；对账结果 CONVERGED 才提示可进验收。

## 2. 表结构

DDL：`docs/sql/V9.21__spec_artifact_converge.sql`（幂等，已在本地 gen_platform 执行）。

```sql
CREATE TABLE IF NOT EXISTS gen_spec_artifact (
  id              bigint       NOT NULL COMMENT '主键（应用层雪花ID）',
  project_id      bigint       NOT NULL COMMENT '项目ID(sys_project.id)',
  artifact_type   varchar(32)  NOT NULL COMMENT '工件类型:CONSTITUTION/SPEC/PLAN/TABLES/TASKS',
  version         int          NOT NULL DEFAULT 1 COMMENT '版本号(同项目同类型递增)',
  title           varchar(200) DEFAULT NULL COMMENT '标题',
  yaml_meta       text                    COMMENT '结构化元数据JSON',
  content_md      mediumtext              COMMENT 'Markdown正文(人与Agent共读)',
  structured_json mediumtext              COMMENT '期望清单JSON(converge比对数据源)',
  status          varchar(16)  NOT NULL DEFAULT 'DRAFT' COMMENT '状态:DRAFT/CONFIRMED',
  deleted         tinyint      NOT NULL DEFAULT 0 COMMENT '逻辑删除',
  create_by       bigint       DEFAULT NULL,
  create_time     datetime     DEFAULT NULL,
  update_by       bigint       DEFAULT NULL,
  update_time     datetime     DEFAULT NULL,
  PRIMARY KEY (id),
  KEY idx_spec_project_type (project_id, artifact_type, version)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='SDD规格工件(V9.21)';
-- gen_converge_report / gen_converge_item 结构同风格，见 DDL 文件
```

## 4. 接口设计（已实现，GenSpecController）

| 接口 | 方法 | 路径 | 请求 | 响应 |
|---|---|---|---|---|
| F-01 | GET | `/gen/spec/tree` | ?projectId | `data:[GenSpecArtifact]`（五类最新） |
| F-02 | GET | `/gen/spec/{id}` | id | `data:GenSpecArtifact` |

3. **业务异常落 500**：IllegalStateException/IllegalArgumentException 未被 GlobalExceptionHandler 映射。修复：统一改 `BusinessException(400, …)`
