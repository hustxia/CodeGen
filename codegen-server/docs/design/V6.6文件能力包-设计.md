# V6.6 文件能力包——设计

> 2026-10-27。对应需求 `docs/requirements/V6.6文件能力包-需求.md`。

## 表结构

`sys_file` 是**产物**基座表（不是平台库表），DDL 由 scaffold 写盘 `db/file.sql`，PipelineExecutor 与 pay.sql 同模式导入产物库：

```sql
CREATE TABLE IF NOT EXISTS sys_file (
  id bigint NOT NULL AUTO_INCREMENT COMMENT '文件ID',
  original_name varchar(255) NOT NULL COMMENT '原始文件名',
  storage_name varchar(128) NOT NULL COMMENT '落盘文件名（uuid.ext）',
  relative_path varchar(255) NOT NULL COMMENT '相对 upload-dir 的路径（yyyyMMdd/uuid.ext）',
  url varchar(512) NOT NULL COMMENT '访问URL（/uploads/...）',
  content_type varchar(128) DEFAULT NULL COMMENT 'MIME类型',
  file_size bigint NOT NULL DEFAULT 0 COMMENT '字节数',
  md5 char(32) DEFAULT NULL COMMENT 'MD5（预留去重）',
  biz_type varchar(64) DEFAULT NULL COMMENT '业务归类（预留）',
  deleted tinyint NOT NULL DEFAULT 0 COMMENT '逻辑删除',
  create_by varchar(64) DEFAULT '' COMMENT '创建人',
  create_time datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  update_by varchar(64) DEFAULT '' COMMENT '更新人',
  update_time datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  remark varchar(255) DEFAULT NULL COMMENT '备注',
  PRIMARY KEY (id),
  KEY idx_relative_path (relative_path)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='系统文件';
```

种子数据：无（文件表天然无种子；S8 用真实上传验证）。

## 功能设计

| 编号 | 功能点 | 位置 | 实施要点 |
|---|---|---|---|
| F-01 | html_type 扩展 | `GenTemplateModel` 列模型 + `vuePage.ftl` | 新增 `isImage`（htmlType=='image'）/`isFile`（=='file'）两个派生标志，唯一实现在 GenTemplateModel，模板只消费 |
| F-02 | 列名推断 | 平台 `GenTableServiceImpl` 导入表逻辑 | 推断规则一个私有方法 `inferHtmlType(columnName)`，仅当列类型是 varchar 且用户未显式选择时作默认值 |
| F-03 | 产物基座 | `scaffold-file/` 资源文件（V6.3 pay 包模式，`__PKG__` 占位） | FileController / FileInfo 实体 / FileMapper / FileProps（`@Value ${file.upload-dir:./uploads}` `${file.max-size-mb:10}` 白名单）/ FileApiPerms（upload+download 注册为仅登录，page/remove 走权限点）/ WebMvcConfig 静态映射 `/uploads/**`（随 fileEnabled 条件注入，不动产物已有 config 时合并进现有 WebMvcConfig 生成逻辑） |
| F-03-a | 上传流程 | FileController.upload | 校验扩展名白名单+大小 → `upload-dir/yyyyMMdd/uuid.ext` 落盘 → 插 sys_file → 返回 `{id, url, name, size}`；IOException → BusinessException「文件保存失败」 |
| F-03-b | 下载流程 | FileController.download | 按 id 查 sys_file → `Paths.get(uploadDir, relativePath).normalize()` 且必须 `startsWith(uploadDir)`（双保险防穿越）→ `Content-Disposition: attachment; filename*=UTF-8''原名` |
| F-03-c | yml | `applicationYml(+fileEnabled)` | 顶层 `file:` 块（upload-dir / max-size-mb / 白名单可省略用内置默认），沿用 V6.3 坑 40：顶层键块放 yml 末尾 |
| F-04 | 前端组件 | 产物 `src/components/ImageUpload.vue` / `FileUpload.vue`（资源文件，`__PKG__` 不涉及，纯前端无需替换） | el-upload custom-request 走 utils/request（带 token、baseURL 相对路径 `/file/upload`）；ImageUpload：单图回填 URL 字符串，`multiple` 模式逗号分隔；FileUpload：显示文件名+下载链接；错误 message 透出后端 msg |
| F-05 | 模板渲染 | vuePage.ftl 四处分支 | ① 表单：image → `<image-upload v-model="form.x"/>`；file → `<file-upload v-model="form.x"/>` ② 列表：image → el-image 缩略图（:src + preview-src-list，空值显示占位）；file → el-link 下载 ③ 详情抽屉：同列表 ④ 组件全局注册：产物 main.js 追加（scaffold mainJava 模板同步） |
| F-06 | 子表行 | vuePage.ftl 子表/明细模板分支 | 子表行内 image → 小号上传；file → 文件名+删除重传 |
| F-07 | 平台前端 | codegen-web `table/index.vue` htmlTypes 数组 | 追加 `{value:'image',label:'图片上传'}` `{value:'file',label:'文件上传'}`；htmlType 变更联动逻辑（dictType 清空等）对两新值同 input 处理 |

## 接口设计（产物基座）

| 接口 | 方法 | 路径 | 请求体 | 响应 |
|---|---|---|---|---|
| 上传 | POST | /file/upload | multipart/form-data `file` | `{code:200,data:{id,url,name,size}}` |
| 下载 | GET | /file/download/{id} | — | 文件流（Content-Disposition 原始名） |
| 文件分页 | POST | /file/page | `{pageNum,pageSize,originalName?}` | `records/total` |
| 删除 | DELETE | /file/{id} | — | `{code:200}`（逻辑删，物理文件保留） |
| 图片直链 | GET | /uploads/{yyyyMMdd}/{name} | — | 静态资源（WebMvcConfig 映射，不走鉴权） |

约定遵循：统一 `{code,msg,data}`、错误 HTTP 200 + body.code、Long 主键序列化字符串、路径前缀走网关 `{gateway_prefix}/file/...`。

### S8 实测暴露并修复的 6 个真缺陷（都已回写真源）

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 所有上传被拒「不支持的文件类型：.png」 | `extOf` 返回带点 `.png`，白名单存不带点 `png`，`contains` 恒 false | extOf 统一返回不带点；报错文案补 `.` |
| 2 | 白名单列表拿不到配置默认值 | `@Value("#{'${file.allowed-exts:jpg,png,...}'.split(',')}")` SpEL + 含逗号默认值组合解析不稳 | 改 String 注入 + 手动 split/trim/toList，`getAllowedExts()` 现算 |
| 3 | 图片直链 401 | `/uploads/**` 不在 AuthContextFilter 白名单（Filter 拦所有请求） | 白名单随 fileEnabled 追加 `"/uploads"` |
| 4 | 11MB 上传 500 | 两层限制都没配：Spring multipart 默认 1MB、Tomcat `max-http-form-post-size` 默认 10MB | yml 加 `spring.servlet.multipart`（20/25MB）+ `server.tomcat.max-http-form-post-size: 25MB` |
| 5 | 上传响应 `id` 是 JSON number，JS 截断后回传查不到记录 | `LongIdJacksonConfig` 只对 **bean 属性** 生效，`Map.put("id", Long)` 绕过保护 | upload 响应 `String.valueOf(record.getId())` |
| 6 | yml multipart 配置静默失效 | `servlet:` 缩进写成 4 空格 → 落成 `application.servlet` | 缩进改 2 空格（spring 直接子键）；注释里写明这个坑 |
