## 一、表结构

### 1.1 新增 `sys_language`（平台级语言清单，只读镜像）

语言清单的**唯一真源是 classpath 的 `src/main/resources/i18n/languages.json`**（编译进 jar，随版本走）。
建这张表是为了让 SQL 侧（报表、字典、外部系统）也能查到同一份数据，并在库里留一份可审计的镜像。
**平台运行时不依赖此表**——表不存在时接口仍能从 JSON 返回全部语言。

```sql
CREATE TABLE IF NOT EXISTS sys_language (
  id bigint NOT NULL AUTO_INCREMENT,
  lang_code varchar(32) NOT NULL COMMENT '语言码(ISO 639-1 或 BCP47 变体)',
  iso639_2 varchar(8) NULL COMMENT 'ISO 639-2 三字母码',
  locale_tag varchar(32) NOT NULL COMMENT '默认 BCP47 标签,用于 <html lang> / Locale.forLanguageTag',
  name_en varchar(128) NOT NULL COMMENT '英文名',
  name_zh varchar(128) NOT NULL COMMENT '简体中文名',
  name_native varchar(128) NOT NULL COMMENT '本地语言自称',
  region varchar(16) NULL COMMENT '默认地区码',
  script varchar(16) NOT NULL DEFAULT 'Latn' COMMENT '文字体系(ISO 15924)',
  dir varchar(8) NOT NULL DEFAULT 'ltr' COMMENT '书写方向 ltr/rtl',
  readme_file varchar(64) NULL COMMENT '对应 README 语言版文件名(空=暂无译本)',
  enabled tinyint NOT NULL DEFAULT 1 COMMENT '是否启用',
  sort_no int NOT NULL DEFAULT 0 COMMENT '显示顺序',
  deleted tinyint NOT NULL DEFAULT 0,
  created_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_lang_code (lang_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci COMMENT='项目语言配置表';
```

> 与 `BaseEntity` 的差异：`sys_language` 用 `created_at/updated_at`（与 `sys_dict_*` 一致），
> 因此**不建 MyBatis-Plus 实体**，查询走 `JdbcTemplate`；理由同 `DictService` 注释。

### 1.2 `sys_project` 追加两列（幂等）

```sql
ALTER TABLE sys_project ADD COLUMN default_language varchar(32) NULL COMMENT '默认语言BCP47标签(空=zh-CN)';
ALTER TABLE sys_project ADD COLUMN supported_languages text NULL COMMENT '启用语言码,逗号分隔(空=全部启用)';
```

实际交付脚本用 `information_schema.COLUMNS` + `PREPARE` 条件执行（坑库 `mysql.md` #2：
裸 `ADD COLUMN` 重跑必报 1060）。**刻意不写 `AFTER <旧列>`**——坑库 mysql.md 的 V6.5 事故
就是 `AFTER mobile_enabled` 在缺列环境里悬空，阻断了后续所有版本脚本。

## 二、功能设计

| 编号 | 功能点 | 页面/位置 | 字段与操作 | 状态流转 | 验收标准 |
|---|---|---|---|---|---|
| F-01 | 语言清单加载 | 后端 `LanguageConfig` 启动加载 JSON | 206 条，含 code/locale/三语名/script/dir | 只读 | 启动日志出现 `206 languages` |
| F-02 | 语言下拉数据 | `GET /language/options` | label=`名称（本地自称）`，value=`locale` | — | 前端下拉 206 项，含 RTL 标记 |
| F-03 | 系统默认语言 | 系统配置弹窗 → 默认语言下拉 | `form.defaultLanguage` → `sys_project.default_language` | 空 → `zh-CN` | 保存刷新后回显 |
| F-04 | 系统启用语言 | 系统配置弹窗 → 启用语言多选 | `form.supportedLanguages`（数组 ↔ 逗号串） | 空 → 全部 | 保存后生成物按该集合输出 |
| F-05 | 生成物 lang/dir | 模板渲染模型 + 脚手架写盘 | `lang` / `dir` 注入 `<html>` | 默认 `zh-CN`/`ltr` | 未配置系统输出不变 |
| F-06 | 回落链 | `LanguageResolver` | 表级 → 系统 → `application.yml` → `zh-CN` | 单一实现 | 与 `GenPathResolver` 同样只在一处实现 |

### 页面结构

- 位置：`src/views/gen/project/index.vue` 的「系统编辑/新增」弹窗，插在「Logo 地址」与「状态」之间
- 查询区：无（语言清单只读，不做分页；206 条走前端本地过滤）
- 表单字段：
  - **默认语言**：`el-select` + `filterable`，选项 206 个，`label = 中文名（本地自称）`，附 RTL 标签
  - **启用语言**：`el-select multiple` + `filterable` + `collapse-tags`，留空即全部启用
- 表单校验：语言码非清单内 → 下拉框限制选择，不会传入非法值；保存时后端二次校验
- 异常提示：接口失败沿用全局拦截器提示；`supportedLanguages` 为 `text`，超长不截断校验（前端限制最多全选 206 项）

## 三、接口设计

统一 `{code, msg, data}`；**前端路径不带 `/api`**（dev 代理 `/dev-api` 去前缀，见 `references/项目适配.md`）。
语言清单为只读，沿用平台既有鉴权，不新增白名单。

| 接口 | 方法 | 路径 | 请求体 | 响应 |
|---|---|---|---|---|
| 全量清单 | GET | `/language/list` | — | `Result<List<LanguageVO>>`，206 条，按 `sortNo` |
| 下拉选项 | GET | `/language/options` | — | `Result<List<LanguageOptionVO>>`，`{label,value,dir,script}` |
| 按码查询 | GET | `/language/{code}` | — | `Result<LanguageVO>`；不存在返回 `code=500` + 提示 |
| 按方向筛选 | GET | `/language/list?dir=rtl` | — | `Result<List<LanguageVO>>`，12 条 RTL |
| 系统配置保存 | PUT | `/project` | `SysProject`（含 `defaultLanguage` / `supportedLanguages`） | `Result<Void>` |

`LanguageVO` 字段（与 `languages.json` 一一对应）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | String | ISO 639-1 或 BCP47 变体，如 `zh` / `zh-TW` / `pt-BR` |
| `iso6392` | String | 三字母码 |
| `locale` | String | 默认 BCP47 标签，如 `zh-CN` / `ar-SA` |
| `nameEn` / `nameZh` / `nameNative` | String | 英文 / 简体中文 / 本地自称 |
| `region` | String | 默认地区码 |
| `script` | String | ISO 15924 文字体系，如 `Hans` / `Arab` / `Cyrl` |
| `dir` | String | `ltr` / `rtl` |
| `readme` | String | 对应 README 译本文件名，可空 |
| `enabled` / `sortNo` | boolean / int | 启用状态 / 显示顺序 |
