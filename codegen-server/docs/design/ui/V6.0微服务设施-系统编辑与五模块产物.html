    微服务时网关占用 8131（服务端口+1）
    选择「微服务设施」后的产物目录结构（后端工程根）
    D:/proj/wms-server/ ← backendRoot（原样不变） ├── pom.xml ← 聚合 pom + spring-cloud / alibaba BOM + gateway 模块条目 ├── wms-common/ ← 基座（同多模块，不变） ├── wms-domain/ ← entity + mapper（同多模块，不变） ├── wms-service/ ← controller + service + dto/vo │ └── src/main/java/com/wms/remote/RemoteSampleClient.java ← Feign 骨架 ├── wms-bootstrap/ ← 启动壳 │ ├── pom.xml ← + nacos-discovery/config + openfeign + loadbalancer │ ├── src/main/java/com/wms/WmsApplication.java ← + @EnableFeignClients │ └── src/main/resources/ │ ├── application.yml ← + spring.application.name + nacos 开关(默认false) + Feign 直连 url │ └── bootstrap.yml ← Nacos 配置中心接入（注释态，启用时放开） └── wms-gateway/ ← V6.0 新增：统一入口 ├── pom.xml ← gateway + nacos-discovery + loadbalancer + nacos-config ├── src/main/java/com/wms/gateway/WmsGatewayApplication.java └── src/main/resources/application.yml ← port 8131 + 路由（catch-all → wms-bootstrap）
    子模块目录 V6.0 新增/变更 依赖链：domain → common，service → domain，bootstrap → service；gateway 独立（webflux）
    网关路由配置（wms-gateway/src/main/resources/application.yml，节选）
    # 统一入口：按业务模块聚合路由；M1 只有单一业务服务，先放 catch-all，拆服务后按注释示例细分 server: port: 8131 # 服务端口 + 1 spring: application: name: wms-gateway cloud: nacos: discovery: enabled: false # ← 默认关：直连本机业务服务，与多模块行为一致 server-addr: 127.0.0.1:8848 gateway: globalcors: cors-configurations: '[/**]': { allowedOriginPatterns: "*", allowedMethods: "*", allowedHeaders: "*" } routes: - id: business uri: http://localhost:8130 # 关 Nacos：直连；开启后改 lb://wms-bootstrap predicates: [ Path=/** ] # 拆服务后按模块聚合（示例）： # - id: order { uri: lb://wms-order, predicates: [ Path=/order/** ] } # - id: stock { uri: lb://wms-stock, predicates: [ Path=/stock/** ] }
    鉴权：网关透传不解析 token 头，各服务 AuthContextFilter 自行校验
    OpenFeign 骨架（wms-service/src/main/java/com/wms/remote/RemoteSampleClient.java）
    // 跨服务调用约定：M1 只给骨架，接口按需手写；name 指向业务服务注册名 @FeignClient(name = "wms-bootstrap", url = "${wms.remote.bootstrap-url:}") // url 有值=直连（默认 false 模式）；清空=走注册中心负载均衡 public interface RemoteSampleClient { @GetMapping("/actuator/health") String health(); }
    bootstrap application.yml 默认下发 wms.remote.bootstrap-url: http://localhost:8130（直连可用）； 开启 Nacos 后把该值清空即自动走 lb://
