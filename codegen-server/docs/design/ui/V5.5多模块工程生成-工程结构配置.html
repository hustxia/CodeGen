③ multi 系统 scaffold + apply 后的产物目录树（F-02/F-03）

示例：仓库管理系统 wms，rootPackage = com.wms。业务产物按模板归属落模块，前端工程不拆。
./demo-target/ ├── wms-parent/ ← backendRoot（聚合 pom 根） │ ├── pom.xml parent：modules 聚合 + 依赖版本管理 │ ├── wms-common/ 基座：exception/config/util/log/auth │ │ ├── pom.xml │ │ └── src/main/java/com/wms/common/… Result / BaseEntity / LogAspect / MaskUtils… │ ├── wms-domain/ entity + mapper(+xml)　依赖 → common │ │ ├── pom.xml │ │ └── src/main/java/com/wms/domain/{entity,mapper}/ │ ├── wms-service/ controller + service + dto/vo　依赖 → domain │ │ ├── pom.xml │ │ └── src/main/java/com/wms/service/{controller,service,dto,vo}/ │ └── wms-bootstrap/ 启动壳　依赖 → service │ ├── pom.xml spring-boot-maven-plugin 在这层 │ ├── src/main/java/com/wms/WmsApplication.java @MapperScan → com.wms.domain.mapper │ └── src/main/resources/application.yml └── wms-web/ 前端工程不拆，仍单工程 └── src/views/{module}/… index.vue / print.vue 等，路径不变
生成产物落位：entity/mapper → domain，controller/service/serviceImpl*/dto/vo → service，基座 → common，pom/启动类/yml → bootstrap；模块前缀在模板渲染源头插入一次，预览 / 写盘 / ZIP 三通道同一路径。
