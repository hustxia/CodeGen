系统管理 / 编辑系统 V5.5 新增「工程结构」字段
多模块（微服务就绪）▼新增
单模块（跟随默认）：现有结构，controller/service/entity 同一 src；
多模块：生成 parent + common/domain/service/bootstrap 四个子模块，模块边界即未来微服务拆分线，改动后下次生成生效
选择「多模块」后的产物目录结构（后端工程根）
D:/proj/wms-server/ ← backendRoot（原样不变） ├── pom.xml ← 聚合 pom（parent） ├── wms-common/ ← 基座：exception/config/util/DictTexts │ ├── pom.xml │ └── src/main/java/com/wms/common/ ├── wms-domain/ ← entity + mapper（生成物落这里） │ ├── pom.xml │ └── src/main/java/com/wms/domain/{entity,mapper}/ ├── wms-service/ ← controller + service + dto/vo │ ├── pom.xml │ └── src/main/java/com/wms/service/ └── wms-bootstrap/ ← 启动壳：XxxApplication + application.yml ├── pom.xml ← spring-boot-maven-plugin └── src/main/java/com/wms/WmsApplication.java
子模块目录 聚合 pom 模块 pom 依赖链：domain → common，service → domain，bootstrap → service
