إجمالي ٢ · RTL 镜像布局

机制：src/utils/i18n.js 用 Vue 2.7 原生 Vue.observable 持有 locale； 所有在 render 期间调用过 $t 的组件自动重渲染，无需刷新。
回落链：当前语言非空译文 → 默认语言 → key 本身。占位语言包键齐全、值为空串，切过去不会显示空白。
RTL：切换时 document.documentElement.dir 同步更新，骨架样式用逻辑属性 （margin-inline-start）与 [dir='rtl'] 规则镜像；代码块 / 路径保持 LTR。
零重依赖：不引 vue-i18n，产物 npm install 依赖清单与 V7.5 完全一致。
