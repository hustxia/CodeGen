| sys_user / sys_session / sys_login_log / sys_oper_log / sys_role / sys_menu / sys_role_menu(若基座有) | `scaffold-test/base.sql`（手写 H2 兼容版 + admin 种子行） | scaffold |

H2 兼容转换规则（schema DDL 一律遵守）：去掉 `ENGINE=... DEFAULT CHARSET=... COMMENT='表注释'`；`ON UPDATE CURRENT_TIMESTAMP` 删除；列注释保留 `COMMENT '...'`（H2 支持）；`UNIQUE KEY uk_x (col)` → `CONSTRAINT uk_x UNIQUE (col)`；`KEY idx (col)` → 内联 `INDEX idx (col)`；`AUTO_INCREMENT` 保留（MySQL 模式支持）。

**CrudControllerTest.ftl 断言集**（仅 generated 端点，参考 v66-s8-smoke-b.mjs）：
1. `POST /{module}/page` 带 Bearer token → code=200 且 data.records 为数组
2. `POST /{module}` 新增（saveDto 必填字段取列模型非空列的最小合法值）→ code=200，data 回 id
3. `GET /{module}/{id}` → code=200 且 id 一致（**id 断言按 String 处理**，坑 57）
4. `PUT /{module}` 改一个可空字段 → code=200
5. `DELETE /{module}/{id}` → code=200，再 GET → code!=200（或 deleted 生效）
6. 无 token `GET /{module}/page` → code=401
7. 上下文隔离：`@Sql` 或 @BeforeAll 清业务表（deleted 置 1 即可，逻辑删语义）

**LoginStateTestSupport**（产物侧基类）：
- `@SpringBootTest + @AutoConfigureMockMvc + @ActiveProfiles("test")`
- `@BeforeAll` JdbcTemplate 直插 `sys_session`（token 固定前缀 `it-` + 随机，username=admin，expire=+1h）+ 确保 admin 用户存在（base.sql 种子，幂等）
- 暴露 `mockMvc` 与 `bearer()` 工具方法
- **AuthContextFilter 依赖 sys_user 存在 admin**：base.sql INSERT 种子（同 seedSql 的 BCrypt 值 `$2a$10$BQz...`，密码 admin123）
