1. 登录 OSChina → 个人主页 → 「博客」→「写博客」（编辑器支持 Markdown 与富文本切换，用**富文本**）
2. 用浏览器打开本目录对应的 `*-OSChina.html`
3. 页面内 `Ctrl+A` 全选 → `Ctrl+C` 复制 → 粘贴到 OSChina 编辑器正文区
4. 等待图片上传（HTML 内图片为 base64 内嵌；若 OSChina 未能自动转存图床，见下方备选方案）
5. 标题用下表「标题」列；标签用「标签」列；分类选「博客」
6. 发布后把文章链接登记到下表「已发链接」
