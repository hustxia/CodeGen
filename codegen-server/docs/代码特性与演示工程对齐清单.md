### V9.15 数据可视化图表包细节（本次对齐重点）

- **开关**：`sys_project.chart_enabled` 三态——`NULL/0=关`、`1=开`，唯一回落实现 `GenTemplateModel.resolveChart`；默认关时产物字节级零 diff。
- **图型推导**：`GenChartDeriver.derive()` 纯函数，仅看列元数据（`isNumber/isDate/hasEnum/hasDict/commentLabel…`）产出 pie/line/bar/gauge，**零领域关键词**，杜绝 `GenMenuGroup.RULES` 式领域耦合。
- **聚合接口**：每表 `/{module}/stats`，field 白名单与字段映射生成期内嵌，运行时只与枚举比较，SQL 表名列名全来自生成期常量——防注入。
- **前端**：`ChartCard.vue` 按需引入 ECharts；系列色从 `--app-primary` 读取并用 JS 混色派生（canvas 不认 CSS `color-mix`）；`nextTick` + `ResizeObserver` + `dispose` 成对。
- **看板**：`GenDashboardWriter` 系统级跨表聚合页（非单表 ftl），scaffold/写盘/ZIP/路由/依赖全通道注入。
- **验证**：平台 486/486 单测绿；产物 64 个 StatsController 编译通过；真浏览器 4 类图表 0 控制台错误。
- **设计/需求**：`docs/design/V9.15数据可视化图表-设计.md`、`docs/requirements/V9.15数据可视化图表-需求.md`、`docs/sql/V9.15__chart_enabled.sql`、UI 效果图与运行时截图在 `docs/design/ui/`。

## 四、如何复核「功能最新」（可重复执行）

1. **版本真源**：`grep currentVersion docs/version-history.json` → V9.15。
2. **README 三段一致**：版本表末行 `**current**`、项目状态段版本、核心能力全景特性——三者都应为 V9.15。
3. **源码能力包**：`ls src/main/java/com/codegen/support/GenChartDeriver.java` 存在；`grep resolveChart GenTemplateModel.java` 有唯一回落实现。
4. **前端开关**：`grep chartEnabled codegen-web/src/views/gen/project/index.vue` 有三态定义。
5. **演示工程图表落地**：`find <工程>/src -iname '*StatsController.java' | wc -l` —— police_affairs 应为 64。
6. **重生成验证**：需要让某演示工程体现 V9.15 时，在系统管理里把该项目「数据可视化图表」开关设为开（1），重新走流水线即可；默认关时产物零 diff，不影响既有工程。
