# V6.0 微服务设施（多模块单体到可拆微服务）需求文档

> 日期：2026-10-25　规划：`docs/代码生成器-V6.0-规划.md`　前置：V5.5 多模块（已交付，af73dd3）

## 一、背景与目标

V5.5 交付的是「微服务就绪单体」：模块边界（domain/service/common/bootstrap）画好了，但跨模块仍是进程内直调、单库单配置。本版在 multi 结构上补齐微服务三件套——注册中心（Nacos）、统一入口（Gateway）、跨服务调用（OpenFeign），用户选择 `micro` 第三态即可生成可直接拆分的微服务工程；`nacos.enabled=false`（默认）时产物与 multi 行为一致（两栖运行，没装 Nacos 也能跑通）。

使用方：代码生成器平台用户（系统管理员角色配置工程结构，开发人员消费生成物）。

## 二、功能点

- **F-01 工程结构第三态 'micro'**：`sys_project.project_structure` 增值 'micro'（系统编辑下拉新增「微服务设施」选项）；DDL 只更新列注释，无新列。
- **F-02 五模块脚手架**：`POST /gen/scaffold` 传 `projectStructure='micro'` 时，在 multi 四模块基础上加生成 `<stem>-gateway` 模块（pom + 启动类 + application.yml 路由配置），共五模块。
- **F-03 依赖升级（micro 专属）**：聚合 pom 增加 spring-cloud 2023.0.1 BOM + spring-cloud-alibaba 2023.0.1.0 BOM；bootstrap 模块加 nacos-discovery/config/openfeign/loadbalancer 依赖；gateway 模块加 gateway/nacos-discovery/loadbalancer/nacos-config/bootstrap-starter 依赖（版本矩阵复用 shop 项目实测结论）。
- **F-04 Nacos 开关式降级**：bootstrap 与 gateway 的 application.yml 里 `spring.cloud.nacos.discovery/config.enabled` 默认 false——产物两栖运行；bootstrap.yml 模板提供 Nacos config import 注释态。
- **F-05 Gateway 路由**：M1 生成 catch-all 路由 `Path=/**` → `lb://<stem>-bootstrap`（nacos 关闭时直连 `http://localhost:<serverPort>`），并附按模块聚合的注释示例；网关端口 = serverPort+1；鉴权透传不解析（各服务 AuthContextFilter 自行校验）。
- **F-06 OpenFeign 骨架**：service 模块生成 `remote/` 包示例客户端（`@FeignClient(name="<stem>-bootstrap", url="${<stem>.remote.bootstrap-url:}")`），bootstrap application.yml 默认下发直连 url（false 模式可用，true 模式清空 url 即走 lb）；启动类 micro 时加 `@EnableFeignClients`。
- **F-07 生成期跨系统引用拦截**：主从表子表与主表所属系统（project_id）不一致时，渲染入口报可读错误（多模块/微服务下子表产物必须与主表同模块，跨系统引用是配置事故）。
- **F-08 前端适配**：系统编辑下拉加「微服务设施」+ help 文案；micro 时 apiJs 的 apiBase 计算改为 `/{module}`（走网关模块路由，不再拼 `/api/{gatewayPrefix}`），scaffold 前端代理 target 指向网关端口。

## 三、边界与异常

- `project_structure` 取值域扩为 null/'multi'/'micro'，其余值一律按单模块处理（isMicro/isMulti 严格匹配）。
- multi 与单模块行为零变化（AC4 基线零 diff 是硬门禁）。
- Feign 只给骨架与约定，不按表自动生成跨服务 API（规划定案）。
- scaffold 时业务模块名未知 → gateway 路由用 catch-all + 注释示例（诚实边界）。
- 跨系统引用拦截同时生效于 multi/micro/mono（配置事故任何时候都不该静默生成错代码）。

## 四、验收标准

- [ ] AC1 `projectStructure='micro'` 生成五模块产物，gateway 模块含路由配置与启动类
- [ ] AC2 micro 产物 `nacos.enabled=false` 默认态：五模块 `mvn compile` 通过，bootstrap 可启动到 banner
- [ ] AC3 `nacos.enabled=true` + 本机 Nacos：服务注册可见，网关按路由转发业务接口实测通（可降级手测）
- [ ] AC4 multi 系统生成产物与 V5.5 基线零 diff；单模块系统零影响
- [ ] AC5 主从表跨系统引用生成期报错，文案可读
- [ ] AC6 Feign 骨架 false 模式 url 直连可用；true 模式清空 url 走 `lb://`
- [ ] AC7 `mvn test` 141 + 新增 micro 用例全绿（基线含 micro 场景快照）
- [ ] AC8 系统编辑页三态（含微服务）保存回显正确
