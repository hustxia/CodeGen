## 背景与目标

平台的文档资产（需求单、验收单、外部设计稿）是 Word/PDF，目前只能在本地打开。V6.6 的文件能力包**只做进产物工程**，平台侧没有上传、存储、预览任何一块基座。

本版给平台补「文档中心」：上传 Word/PDF → 列表 → 在线预览（PDF 原生渲染，Word 双引擎）→ 下载/删除。**不开放任何免登录直链**，所有文件访问走鉴权接口。

## 功能点

| 编号 | 功能点 | 一句话 |
|---|---|---|
| F-01 | 文档上传 | 白名单 + 大小校验 → `{yyyyMM}/uuid.ext` 落盘 → 写 `sys_doc` 元数据 |
| F-02 | 文档列表 | `POST /doc/page` 分页，支持按名称模糊与按类型（pdf/word）筛选 |
| F-03 | 文档下载 | 按 id 查库取路径流式下载，`Content-Disposition: attachment` 带原始中文名 |
| F-04 | 文档删除 | 逻辑删（`deleted=1`），物理文件保留 |
| F-05 | PDF 在线预览 | pdf.js 渲染：翻页 / 跳页 / 缩放 / 适宽 |
| F-06 | Word 在线预览 | 双引擎：`browser`（docx-preview 前端渲染）/ `libreoffice`（服务端转 PDF）/ `auto` 自动探测 |
| F-07 | 预览能力探测 | `GET /doc/meta/{id}` 返回 `previewMode`（pdf / browser-docx / unsupported）与当前引擎 |
| F-08 | 权限 | `doc:list / doc:upload / doc:remove` 菜单权限，**后端校验**（平台此前只有登录态） |
| F-09 | 菜单与路由 | `V6.9__doc_menu.sql` 注册菜单，前端路由 `/doc/index` |
| F-10 | 降级 | `doc.preview.enabled=false` 时预览按钮变下载；`.doc` 在浏览器引擎下提示下载 |
| F-11 | 启动自检 | 打印引擎、soffice 版本、上传/缓存目录可写性 |

## 边界与异常

- **大小**：单文件默认 ≤30MB（`doc.max-size-mb`）；`spring.servlet.multipart.max-file-size: 30MB`、`max-request-size: 35MB` 两层都要配（坑 56：只配一层等于没配）
- **白名单**：默认 `pdf,doc,docx,xls,xlsx,ppt,pptx`；**不含 svg/html/md**（平台不做富文本渲染，避免 V6.6 那类同源 XSS）
- **存储**：`{doc.upload-dir}/{yyyyMM}/{uuid}.{ext}`，默认 `./uploads/doc`；落盘名与原名解耦，原名只入元数据
- **安全**：
  - 平台**不注册** `/uploads/**` 静态映射，所有访问经 `DocController` 校验 token
  - 读文件：`base.resolve(relative_path).normalize()` 后必须仍在上传目录内（双保险防穿越）
  - 预览响应 `Content-Type: application/pdf` + `inline` + `X-Content-Type-Options: nosniff`
  - 前端取流一律 axios `arraybuffer`（带 Authorization 头），**禁止 iframe + `?token=`**
- **Word 引擎**：
  - `auto`（默认）：启动探测 `soffice`，有则服务端转 PDF，无则浏览器渲染
  - `libreoffice`：探测失败 → 启动 WARN + 接口返回明确错误，**不静默降级**
  - 转换并发上限 2、单次超时 60s、每次独立 `-env:UserInstallation`（LO 单实例锁会互相打死）
  - 缓存 `{upload-dir}/.preview/{id}-{size}-{mtime}.pdf`；`sys_doc` 行不可变，无需失效
- **兼容**：新增表与菜单，不改任何既有表结构与接口；现有测试不受影响
- **Long 主键**：响应里的 id 一律字符串下发（坑 57）

## 明确不做（本版本）

- 产物工程的文档预览（V6.6 的 file 字段保持下载能力，接入留 V7.x）
- 在线编辑 / 批注 / 协同（OnlyOffice、金山）
- Excel / PPT 内容级预览（libreoffice 开启时转 PDF 顺带可得，不列验收）
- md / html 文档浏览（`docs/` 目录只读浏览另议）
- 对象存储、分片上传、断点续传、病毒扫描
- 移动端专门适配
