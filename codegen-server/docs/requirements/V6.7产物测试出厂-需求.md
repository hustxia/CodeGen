# V6.7 产物测试出厂 —— 需求文档

> 日期：2026-10-28　来源：`docs/代码生成器-V6.7-规划.md`（用户已过目并拍板「开发6.7」）

## 一、背景与目标

生成的产物工程目前测试为零（pom 无 spring-boot-starter-test、无 src/test），商城迭代里每次改生成物都靠手点回归；平台侧每版 S8 都要重写一遍冒烟脚本里的造登录态/CRUD 断言。本版让**产物打开即 `mvn test` 全绿**：脚手架按 `sys_project.test_enabled` 开关为产物注入测试基建 + 每业务表一份集成测试，测试库用 H2（MODE=MySQL），不依赖 Docker 与外部 MySQL。

## 二、功能点

| 编号 | 功能点 | 一句话 |
|---|---|---|
| F-01 | test_enabled 三态开关链 | sys_project 加列 → resolveTest 唯一回落（NULL/缺省=开，硬编码 1 兜底）→ ProjectConfig/DTO/显式 SET 全链 |
| F-02 | scaffold-test 资源目录 | application-test.yml + schema-test.sql.ftl（H2 兼容，与正式 DDL 同模型产出）+ LoginStateTestSupport + CrudControllerTest.ftl |
| F-03 | pom 测试依赖注入 | testEnabled 时产物 pom 追加 spring-boot-starter-test 与 h2（均 test scope）；单模块与 multi/micro 模块分道 |
| F-04 | 脚手架接线 | src/test 全套写盘 + nextSteps 提示「运行 mvn test」；关开关时零痕迹 |
| F-05 | 无侵入保证 | test_enabled=0 场景产物与旧版逐字节一致，基线快照守卫 |

## 三、边界与异常

- **默认开**：与 file/pay 兜底 0 不同，resolveTest 兜底 1（测试零运行时侵入）；`test_enabled=0` 才关闭。
- **H2 方言墙**：datetime→datetime(6)、tinyint(1)、中文 COMMENT、索引语法等差异集中在 schema-test.sql.ftl 一个文件里消化；S0 已预检（见设计文档验证记录）。
- **登录态**：测试直插 token 持久化表（V6.4 落地），手法与 v66-s8-smoke-b.mjs 一致；不 mock 鉴权链。
- **多模块**：集成测试落在 bootstrap 模块（启动类所在）；单模块落工程根。
- **只测 generated 端点**：不猜业务逻辑断言；主子表只测主表控制器（子表断言 P1 再扩）。
- **flow/file/pay 能力包关闭时**：测试模板按对应模型标志降级（与 vuePage 同款 `<#if>` 分支）。

## 四、验收标准

- [ ] `mvn -o test` 平台全绿，基线新增 test 场景快照入库
- [ ] 新 scaffold 产物在产物根 `mvn test` 实跑全绿（H2，无外部依赖）
- [ ] demo_goods_file 一主一子产物：list/create/update/delete/未登录 401 断言全过
- [ ] test_enabled=0 产物 ZIP 内无 src/test 痕迹，基线快照与旧版逐字节一致
- [ ] 平台前端「测试骨架」开关三态显示、保存、重新生成生效
- [ ] 坑库/知识库/速查/工作日志四项沉淀齐
