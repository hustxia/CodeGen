# 一主多子与级联删除 需求

> 版本：v1.0　日期：2026-10-23　提出人：用户（10-23 会话，规划见 `docs/代码生成器-V4.4-规划.md`）

## 背景与目标

代码生成器当前主子表只支持"一主一子"（引擎 `loadChild` 带 `LIMIT 1`，多张子表挂同一主表时静默丢弃其余）；删除主单不级联，子表数据残留成孤儿。本版让"有关联的表"支持任意多张子表、详情多 tab 一览全部明细、删除可级联可阻止；单表保持最简。

## 功能点

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F-01 | 一主多子：引擎取全部子表 | P0 | `loadChild` 去 `LIMIT 1`，模型 `child.*` → `children[]`，每张子表仍可递归挂孙表 |
| F-02 | 多子生成物循环化 | P0 | serviceImpl / controller / saveDto / vuePage / apiJs 涉及 `child.*` 处改为 `<#list children as child>`，每张子表 CRUD/明细完整 |
| F-03 | 详情接口返回全部子表 | P0 | `/with-children` 响应结构升级（见设计文档接口表） |
| F-04 | 级联删除——级联模式（默认） | P0 | 删主单同事务逻辑删除全部子表行（含孙层），响应带各子表删除行数 |
| F-05 | 级联删除——阻止模式 | P0 | 任一子表存在有效行即拒绝删除，提示各子表行数 |
| F-06 | 级联删除——现状模式（逃生门） | P0 | `mode=2` 与 V4.3 行为完全一致，锁定契约 |
| F-07 | 删除模式配置 | P0 | 表级三档下拉（阻止/级联/不处理）+ 系统级默认（sys_project），独立回落不进 17 开关 |
| F-08 | 详情多 tab | P0 | 详情从 420px 只读抽屉升级为宽抽屉 + el-tabs：tab1 主表键值，tab2..N 每张子表只读明细 |
| F-09 | 批量删除走同一 service 方法 | P0 | 级联/阻止语义对批量删除一致 |
| F-10 | 契约测试固化不变式 | P0 | 5 例：多子级联删净 / 孙层覆盖 / 阻止拒删 / mode2 现状 / 多子详情回归 |

## 边界与异常

| 场景 | 期望行为 |
|---|---|
| 级联模式下子表无行 | 正常删主表，响应行数 0 |
| 阻止模式下多张子表都有有效行 | 提示文案包含**每张**子表的有效行数，一次说全 |
| 阻止模式下部分子表有行 | 同上，有行的报、没行的不提 |
| 批量删除中某一单被阻止 | 整批回滚（同事务），提示定位到具体单据 |
| 三级 + 多子组合 | 每张子表独立递归孙层，互不串扰 |
| `delete_cascade_mode` 值非法（非 0/1/2） | 按 2（现状）处理并 log.warn |
| 详情某子表 0 行 | tab 保留、显示空表，不隐藏 tab |
| 多子化对存量单子表生成物的影响 | 产物结构变化（children 数组化），基线显式更新并在提交说明写明 |
| 老库升级 | `ADD COLUMN NOT NULL DEFAULT 1` 自动填 1，行为从"留孤儿"变"级联删"，发布说明必须写 |
