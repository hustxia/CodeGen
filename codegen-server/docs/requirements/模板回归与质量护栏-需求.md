# 模板回归与质量护栏 需求

> 版本：v1.0　日期：2026-10-22　提出人：项目负责人
> 关联规划：`docs/代码生成器-V4.3-规划.md`

## 背景与目标

代码生成器的产品内核是 12 个 FreeMarker 模板（2,338 行），它们产出每个被接管工程的 Controller / Service / Entity / Vue 页面。当前模板可以**在线修改**（`gen_template` 12 条 + 版本历史），但改完之后：

- 产物变没变、变在哪，只有人眼能发现；
- 写盘 / 漂移 / 回滚三条链路的不变式，只有人写临时脚本验证（V4.2 验收时用的是 `/tmp/e2e.mjs`，跑完即丢）；
- 后端 197 个主类只有 7 个测试类（3.6%），前端 22 个 Vue 文件 0 个测试；
- `npm run lint` 是假命令，`mvn test` 靠人记得跑，没有任何 CI。

**本版目标**：给"改模板 / 改策略"建立可重复的回归锚点，让回归在本地和 CI 上自动暴露，而不是在目标工程编译失败时才发现。

不做会怎样：模板改动继续靠人工试跑，一次误改可能污染多个已接管工程，且无法证明"改之前是好的"。

## 功能点

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F-01 | 产物黄金基线 | P0 | 三个样板用例（simple / relation / master-detail）渲染全部 12 个模板，与仓库内基线逐字节比对 |
| F-02 | 基线只读 + 显式更新 | P0 | 默认只读；更新基线必须传 `-Dgen.baseline.update=true`，防止"跑挂就改基线"抹掉回归 |
| F-03 | 差异可读 | P0 | 不一致时输出 unified diff（文件 + 行号 + 上下文），不是一句 assert failed |
| F-04 | 四条不变式契约测试 | P0 | 用 MockMvc 固化：台账完整、备份可信、回滚可逆、回滚可再回滚 |
| F-05 | 前端策略纯函数 | P0 | 向导三档策略与回滚默认勾选规则抽到 `src/utils/genStrategy.js`，页面只做展示 |
| F-06 | 前端单测 | P0 | vitest 覆盖 F-05 的纯函数，≥12 例 |
| F-07 | lint 假命令修复 | P0 | `npm run lint` 目前报 `command "lint" does not exist`，补齐 eslint 插件或改用直调 |
| F-08 | 一条命令全绿 | P0 | `scripts/verify-all.mjs`：mvn test → vitest → build:prod，任一失败非 0 退出 |
| F-09 | CI 门禁 | P0 | 提交 Gitee Go 流水线配置，push `dev` 触发 |

## 边界与异常

| 场景 | 期望行为 |
|---|---|
| 首次运行、基线目录不存在 | 测试**失败**并提示用 `-Dgen.baseline.update=true` 生成，不静默通过 |
| 传了更新开关 | 允许写基线，但测试输出必须打印"基线已更新 N 个文件"清单，进提交说明 |
| 契约测试连到的库名不含 `_test` | 启动即失败并抛错，绝不写开发库 `gen_platform` |
| 契约测试写盘 | 一律用 JUnit `@TempDir` 沙箱，不碰 `codegen-demo-target` |
| H2 与现有 MySQL 方言 SQL 不兼容 | 改用独立 MySQL schema `gen_platform_test`，不硬啃 H2 |
| `verify-all` 遇到环境缺失（无 JDK / dist 被沙箱拦） | 该项标记 `ENV-SKIP` + 原因，整体退出码 **2**（区别于业务失败的 1），不伪装成功 |
| 基线更新导致 diff 巨大（>200 行） | 测试仍然通过，但打印警告要求人工确认，避免"顺手全量重排" |
| 抽取纯函数改变了现有行为 | 先用"现状快照测试"固化 20 组输入输出，再搬代码；快照必须全绿 |
