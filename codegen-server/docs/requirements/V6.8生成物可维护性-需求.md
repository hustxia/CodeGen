# V6.8 生成物可维护性 — 需求

> 日期：2026-10-28　版本：V6.8　状态：已开发完成（S8 验证通过，见 `docs/design/V6.8生成物可维护性-设计.md` 第四节）
> 来源：`docs/代码生成器-V6.8-规划.md`　前置检索：dev-doc 坑库（mysql.md 三态列可空、spring-boot-3.md dryRun 预检/部分更新）、fullstack-dev 项目适配（codegen 8120/9530、无 `/api` 前缀、写盘→菜单→校验定序）

## 一、背景与目标

悦集商城一次完整落地产生 4 类手改、40+ 处文件修改（8 页外键名称、11 页字典 URL、7 表补 `deleted`、14 处图片尺寸、素材白名单与代理、全站改名），每处修改都面临「重生成会被覆盖」。这使生成器的核心价值（配表即出）在二次迭代时反转为负担。

**目标**：让生成物可被反复重生成——重生成前能看清影响面，手改资产默认不被覆盖，能在项目级配置的信息（品牌/素材/字典）一次配好、全站生效。

## 二、范围（相对规划的两处修正）

规划中的 P0-2（DDL 补审计列）经代码核对 **V5.1 已实现**（`support/GenAuditColumns` 唯一定义 + `GenDdlPatcher` 手动 DDL 补齐 + AI 建模内联），本版只补回归用例，不重写；P0-1 的「差异引擎」也已存在（`GenCodeService.diff` → NEW/UNCHANGED/MODIFIED + 行级 diff），本版做的是**把差异聚合进 apply 的 dryRun 并落地受保护判定**。

保留 6 个功能点：

| 编号 | 功能点 | 说明 |
|---|---|---|
| F-01 | 影响面预览 | `/gen/apply` 的 `dryRun=true` 返回逐文件影响面与汇总（新增/修改/未变/受保护），不再只回一句「只自检」 |
| F-02 | 受保护跳过 | 既有文件且无台账快照（从未由本平台写过）→ 视为用户资产，默认跳过并在影响面里单列「受保护」；显式 `force=true` 才覆盖 |
| F-03 | 素材链路一次生成 | 产物自带 `placeholder.svg`；白名单固定含 `/img`、`/uploads`、`/shop`；前端 devServer 代理清单含 `/img`、`/uploads`（不剥前缀） |
| F-04 | 品牌参数化 | `sys_project` 增 `app_name`/`app_logo`/`app_theme_color`；注入 title、侧边栏、登录页、pom description、README |
| F-05 | 字典脚手架 | 产物自带 `sys_dict_type`/`sys_dict_data` 建表 + 常用种子 + `SysDictController`；前端字典 URL 去 `/api` 硬编码 |
| F-06 | 多图字段与图片尺寸 | 新增 `multiImage` 控件类型（JSON 数组列）；图片展示尺寸统一走 `GenUiDefaults`（唯一实现，默认列表 80px / 详情 120px） |

## 三、边界与异常

- **不改变已有开关语义**：`file_enabled`/`pay_enabled` 等三态不动；新列一律可空（坑库 mysql.md：NOT NULL DEFAULT 会吃掉「未配置」语义）。
- **受保护判定只影响既有文件**：首次生成（文件不存在）永不拦截。
- **品牌字段全可空**：空值回落到工程名、内置 logo、`#e1251b`，存量项目零 diff（除新增占位图与字典 SQL 两个新文件）。
- **字典种子只放通用字典**（`sys_status`/`sys_yes_no`/`order_status`），业务枚举由表级 `dict_type` 声明，生成时校验存在性并告警，不静默。
- **multiImage 仅对 String 列生效**：非字符串列即使命中命名规则也不识别，避免把 varchar 之外的列打坏。
- **无破坏性迁移**：`sys_project` 三次 `ADD COLUMN`，不删不改既有列。

## 四、验收标准

- [x] 连续两次 `dryRun=true` 调 `/gen/apply`，第二次影响面汇总为「新增 0 / 修改 0 / 未变 N / 受保护 M」（实测 13 文件：第二次 new=0 mod=0 same=13 prot=0）
- [x] 手改一处生成物后 `overwrite=true` 重生成：该文件出现在「受保护」并被跳过，内容 diff 为空；`force=true` 时可覆盖（实测 SKIPPED→MERGED，台账随之补齐）
- [x] 新生成工程包含 `placeholder.svg`、字典 SQL 与 `SysDictController`，`/img` 未登录直链返回 200（实测产物 jar 启动后 `/img/placeholder.svg` = 200 image/svg+xml）
- [x] 品牌三项配置后，title / 侧边栏 / 登录页 / pom description / README 五处一致（favicon 同步吃 Logo；空 Logo 回落 placeholder.svg）
- [x] `multiImage` 字段在列表有缩略图、表单可多图上传、详情可预览；图片尺寸单源默认 80/120，模板无 `44px`/`64px` 残留（实现位置为 `GenTemplateModel.IMAGE_LIST_SIZE/IMAGE_DETAIL_SIZE`，规划中的 `GenUiDefaults` 未采用）
- [x] 平台 `mvn -o test` 全绿（186 例），前端 vitest 22 例通过；S8 冒烟 64 断言 + UI 层走查 ALL PASS
