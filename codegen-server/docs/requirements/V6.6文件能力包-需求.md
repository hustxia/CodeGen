# V6.6 文件能力包——需求

> 2026-10-27。用户指令：不做商城 V2，先做代码生成器，把图片文件上传下载做了。

## 背景与目标

生成的产物工程目前对图片/文件字段只能用文本框存 URL 字符串——没有上传入口、没有缩略图展示、没有下载。本版本给生成器加**文件能力包**（对标 V6.3 支付能力包、V6.5 移动端包）：产物工程开箱即得「上传→落盘→元数据→URL 访问/下载→页面组件自动渲染」全链路。

## 功能点

| 编号 | 功能点 | 一句话 |
|---|---|---|
| F-01 | 表单类型扩展 | 平台建表配置的 html_type 新增 `image`（图片上传）与 `file`（文件上传）两个选项 |
| F-02 | 列名自动推断 | 导入表时列名匹配 `image/pic/img/photo/logo/avatar/cover/icon` → 默认 image；`file/attachment/annex` → 默认 file（人工可改，仅默认值） |
| F-03 | 产物基座上传下载 | scaffold 注入 `sys_file` 元数据表 + FileController（上传/下载/分页/删除）+ 静态资源映射 + yml 配置块 + 权限豁免 |
| F-04 | 产物前端上传组件 | 产物内置 ImageUpload / FileUpload 组件（el-upload + 带 token 的 request 封装） |
| F-05 | 生成页面自动渲染 | vuePage.ftl：html_type=image 的列 → 表单渲染图片上传、列表渲染缩略图（可预览）、详情同；file 列 → 文件上传/下载链接 |
| F-06 | 子表/明细行支持 | 一主多子与详情抽屉里的子表行同样支持 image/file 控件 |
| F-07 | 平台配置界面 | codegen-web 表格配置列下拉加两个选项（与 F-01 同一件事的前端侧） |

## 边界与异常

- **上传限制**：扩展名白名单（图片 jpg/jpeg/png/gif/webp/svg；文件另含 pdf/word/excel/zip/txt/csv），单文件默认 ≤10MB（yml 可配），超限/越界返回明确错误
- **安全**：下载按 id 查库取路径，**绝不拼接用户输入路径**（防路径穿越，知识库要点）；上传文件名脱敏（只取扩展名，落盘名用 uuid）
- **存储**：本地磁盘 `{file.upload-dir}/{yyyyMMdd}/{uuid}.{ext}`（默认 `./uploads`），不做对象存储（明确不做，接口留扩展位）
- **URL 相对路径**：前端一律走 baseURL 相对路径（`/file/upload`），禁止硬编码网关前缀——2026-10-27 商城字典坑的教训
- **幂等/重复**：不做 hash 去重（元数据表预留 md5 列，P1 再启用）
- **兼容**：已有 html_type 数据零影响；image/file 是纯新增枚举值

## 验收标准

- [ ] AC1 平台建表配置出现「图片上传/文件上传」选项，选中后生成的 vuePage 表单渲染上传组件
- [ ] AC2 导入含 image 列的表自动推断为图片上传类型
- [ ] AC3 产物 `mvn package` 编译零错误，出现 sys_file 表与 /file 端点
- [ ] AC4 上传 jpg ≤10MB 成功返回 url，直接访问 url 可打开图片
- [ ] AC5 上传 exe / 超限文件被拒绝且提示明确
- [ ] AC6 下载按 id 走流，响应头 Content-Disposition 带原始文件名；构造穿越 id 无效
- [ ] AC7 生成页面：表单上传→保存→列表显示缩略图→点击预览→编辑回显
- [ ] AC8 平台 `mvn test` 全绿（含新增基线场景），vuePage 基线含 image/file 分支快照

## 明确不做（本版本）

- 对象存储（OSS/COS）对接：接口留 StorageService 扩展位，本版本只做本地盘
- 大文件分片/断点续传：知识库有沉淀但产物场景用不上
- 文件管理独立页面：sys_file 元数据表先服务上传/下载，管理页 P1 用生成器自举
- 图片压缩/水印/裁剪
- 平台自身（codegen-web）的上传需求：平台没有图片字段
