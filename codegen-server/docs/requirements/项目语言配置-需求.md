# 项目语言配置 需求

> 版本：v1.0　日期：2026-11-11　提出人：项目所有者

## 背景与目标

代码生成器平台此前**完全没有任何语言配置能力**：后端无 `MessageSource` / `messages_*.properties`，
前端无 `vue-i18n`，数据库无语言表，生成物里 `<html lang="zh-CN">` 与全部中文提示文案都是硬编码。
仓库根目录虽然已有 48 个 `README_XX.md` 多语言版，但那只是**文档译本**，不构成平台能力：
平台无法回答「这个系统支持哪些语言」「默认语言是什么」「RTL 怎么排」。

本次要补的是**项目级语言配置**（不是把平台界面翻译成 100 种语言）：
给平台一份权威、结构化、可查询、可选配的世界语言清单，并把「默认语言 / 启用语言」
挂到既有的 `sys_project`（一套系统 = 一套输出配置）上，让生成物能按系统配置输出 `lang`、
书写方向与前端展示名。

**不做会怎样**：多语言只能靠改代码和改模板，每接一个海外项目都要重新硬编码一次；
README 语言清单与平台能力脱节；RTL 语言（阿拉伯语/波斯语/乌尔都语/希伯来语）无法在生成物里正确声明。

## 功能点

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F-01 | 权威语言清单数据 | P0 | 覆盖 **100+ 种**世界语言；数据由 JDK 21 CLDR（ISO 639-1）生成，不手工编造译名 |
| F-02 | 语言元数据完整 | P0 | 每种语言含 `code` / `iso639-2` / BCP47 `locale` / 英文名 / 中文名 / 本地自称 / 地区 / 文字体系 / 书写方向(ltr·rtl) |
| F-03 | 单一真源 | P0 | `src/main/resources/i18n/languages.json` 编译进 jar，是唯一真源；SQL 表是它的可选落库镜像 |
| F-04 | 语言查询接口 | P0 | 后端提供全量列表、按码查询、下拉选项、按方向筛选四种查询 |
| F-05 | 系统级语言配置 | P0 | `sys_project` 增 `default_language` / `supported_languages`，沿用「表级 → 系统 → 全局」回落链，空值回落 `zh-CN` / 全部启用 |
| F-06 | 系统配置页可选语言 | P0 | 前端「默认语言」下拉 + 「启用语言」多选，选项来自 F-04 接口，显示本地自称与中文名 |
| F-07 | 生成物注入 lang/dir | P0 | 生成物 `<html lang>` 与 `dir` 从系统配置取，默认 `zh-CN` / `ltr` 保持向后兼容 |
| F-08 | 迁移脚本幂等 | P0 | `docs/sql/V7.5__language_config.sql` 可重复执行；同步 `schema-test.sql` 与实体（见坑库 V6.5 事故） |
| F-09 | 与文档译本关联 | P1 | 语言清单里的 `readme` 字段指向仓库已有的 48 个 README 译本，把文档与平台能力对齐 |

## 边界与异常

| 场景 | 期望行为 |
|---|---|
| 未配置语言（存量系统） | `default_language` 为 NULL → 回落 `zh-CN`；`supported_languages` 为 NULL → 全部 206 种启用，行为与改造前一致 |
| 配了不存在的语言码 | 接口返回 `code=500` + 明确提示；生成时回落到 `zh-CN`，不抛异常中断生成 |
| 语言码大小写 / `zh_CN` 写法 | 统一按 `-` 分隔的 BCP47 标签比对，大小写不敏感 |
| RTL 语言 | 清单里 `dir=rtl`，生成物输出 `dir="rtl"`；代码块/路径仍保持 LTR |
| 语言清单为空或文件损坏 | 启动时降级为内置最小清单（`zh-CN` / `en-US`），不阻断服务启动 |
| 数据归属 | 语言清单是**平台级静态配置**，不属于任何单个系统；系统只保存「选了哪些」 |
| 界面文案翻译 | **本次不含**平台自身界面 100+ 语言翻译（无译文源，且收益不明确）；本次交付的是「配置能力 + 生成物注入点」，后续接 `vue-i18n` 时可直接复用本清单 |
| 并发 / 权限 | 语言清单只读，无并发写；查询接口沿用平台既有鉴权，不新增白名单 |

## 验收标准

- [ ] F-01 `languages.json` 中 `total ≥ 100`，实测 206（188 个 ISO 639-1 + 18 个常用 BCP47 变体）
- [ ] F-01 JSON 可被 Jackson 解析，`code` 无重复，`sortNo` 严格递增
- [ ] F-02 12 种 RTL 语言被正确标注（`ar/fa/ur/he/ar-EG/dv/ks/ku/ps/sd/ug/yi`）
- [ ] F-03 JSON 与 SQL INSERT 的语言码集合完全一致
- [ ] F-04 `GET /language/list` 返回 206 条且 `code=200`；`GET /language/xx`（不存在）返回明确错误
- [ ] F-05 空库按序执行 `docs/sql/` 全量脚本后 `SELECT COUNT(*) FROM sys_language` = 206，且两列已加到 `sys_project`
- [ ] F-05 `schema-test.sql` 与实体字段、交付脚本三处对齐（坑库 V6.5 门禁）
- [ ] F-06 系统配置弹窗能选中语言并保存，刷新后回显
- [ ] F-07 存量未配置系统生成的 `<html lang>` 仍为 `zh-CN`；配置为 `ar-SA` 时输出 `lang="ar-SA" dir="rtl"`
- [ ] F-08 `mvn -o compile` 零错误，相关单测通过
