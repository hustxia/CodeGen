# V6.1 工作流双引擎 需求

> 日期：2026-10-25　来源：docs/代码生成器-V6.1-规划.md（编号顺延，与 V6.0 无代码耦合）

## 一、背景与目标

现有产物审批流（V2.2）是「状态机式直线流」：`gen_table.flow_code` 绑定流程，产物 controller 生成 submit/approve/reject 三端点，引擎逻辑为 `sys_flow_def.nodes` JSON 定义的 from→to 流转。真实审批诉求（会签、条件分支、待办中心、完整历史、流程图）全部缺失。

目标：表绑定流程后可切换「内置简易流 / Activiti 8 引擎」两种实现，**产物对外端点契约不变**；流程节点 JSON 自动翻译为 BPMN 并部署；交付待办中心与完整审批历史。

**S0 实测修正（与规划文档的差异）**：

1. `sys_flow_node` 表不存在——节点定义就在 `sys_flow_def.nodes` JSON（varchar 1024）；流水表为 `sys_flow_task`。
2. **现存真 bug**：`controller.ftl:5,587` 引用 `${rootPkg}.common.flow.FlowService` / `FlowRecord`，但 scaffold 基座类清单（`GenScaffoldServiceImpl:151-201`）不含这两个类——绑定 flow_code 的表生成产物**编译不过**；测试零覆盖（基线 6 场景均未设 flowCode）。本版 P0-1 修复。
3. 流程定义不随产物下发：产物库没有 `sys_flow_def`/`sys_flow_task`，builtin 引擎在产物里无定义可读。本版补产物库建表与定义下发。

## 二、功能点

| 编号 | 功能点 | 一句话 |
|---|---|---|
| F-01 | 产物流程基座类补齐 | scaffold 写 `common/flow/FlowService` 接口 + `FlowRecord` + `BuiltinFlowService`（移植平台逻辑，白名单校验保留），修复编译断裂 |
| F-02 | 产物库流程表 | scaffold db 脚本附带 `sys_flow_def`/`sys_flow_task` 建表；绑定流程的定义 INSERT 随脚本下发 |
| F-03 | flow_engine 双引擎开关 | `sys_project.flow_engine`（builtin 缺省/activiti），产物按值装配 FlowService 实现 |
| F-04 | Activiti 引擎实现 | 产物 pom 引 activiti-spring-boot-starter 8.x + Alfresco 仓库；`ActivitiFlowService` 走 RuntimeService/TaskService/HistoryService；排除引擎自带 Spring Security 自动装配，身份经 IdentityService 桥接 |
| F-05 | BPMN 自动翻译与部署 | `GenBpmnBuilder`：节点 JSON → BPMN2.0 XML（顺序 UserTask + ExclusiveGateway 条件分支 + 驳回网关）；流水线部署步幂等部署；BPMN XML 落 `sys_flow_def.bpmn_xml` |
| F-06 | 待办中心（产物端点） | `GET /flow/todo`（我的待办）、`GET /flow/done`（已办）、`GET /flow/task/{taskId}`（任务详情）；activiti 引擎走引擎表，builtin 引擎基于 sys_flow_task + 当前节点角色模拟 |
| F-07 | 审批历史升级 | activiti 引擎 ACT_HI_* 为主，`/flow/records` 返回兼容视图（从引擎历史投影成 FlowRecord 结构） |
| F-08 | 前端待办中心页 | codegen-web 产物侧新增「待办中心」：待办/已办两个 tab、审批弹窗（通过/驳回/意见）、审批记录时间线 |
| F-09 | 流水线接线 | scaffold/生成产物含引擎时自检展示「N 个流程已部署」；回归：builtin 缺省产物与 V6.0 时点零 diff |

## 三、边界与异常

- `flow_engine` 为空 = builtin，行为与现状一致（含 F-01 修复后的编译可用性）
- Activiti 依赖不在中央仓库：产物 pom 内置 Alfresco `<repositories>`；平台侧自检加「依赖可解析」提示；离线环境须预拉依赖（文档说明）
- 会签/或签/委派/流程图渲染为 P1，本版不做门禁；设计保持 FlowService 接口隔离，将来切 Flowable 7 只换实现
- 产物切换引擎不迁移存量 sys_flow_task 流水（历史留在原表，activiti 历史另起 ACT_HI_*）
