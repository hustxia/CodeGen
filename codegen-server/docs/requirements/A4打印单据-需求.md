# A4 打印单据 - 需求文档

> 版本：V4.5 | 起草：2026-10-23 | 依据：`docs/代码生成器-V4.5-规划.md`（用户已过目）

## 一、背景与目标

主子表业务（订单/台账/单据类）生成物只能看屏幕，打印/归档时用户得自己截图或手工重排。
目标：勾选「打印单据」开关后，一键生成一张排版好的 A4 打印页——抬头、主表信息、全部明细表、合计、签名栏——浏览器 `window.print()` 直接打或另存为 PDF，**生成物零第三方依赖**。

## 二、功能点

| 编号 | 功能点 | 一句话 |
|---|---|---|
| F-01 | 打印页模板 | 生成 `views/{module}/print.vue`，含单据标题/单号/主表键值区/每张子表一个明细块（表头跨页重复+数值列合计）/签名栏 |
| F-02 | 打印开关链路 | `gen_table.gen_print` 表级三态 + `sys_project.default_gen_print` 系统默认 + 硬编码关，三级回落；独立实现不进 17 开关体系 |
| F-03 | 打印入口接线 | 列表操作列「打印」按钮、无 layout 顶层路由 `/print/{module}/:id`、复用既有取数接口 |
| F-04 | 质量护栏 | 基线 4 场景 × 13 模板 = 52 份；契约 +1 例 `printPageContainsA4Layout` |
| F-05 | 产物说明 | readme 记录本 ZIP 是否含打印页 |

## 三、边界与异常

1. **默认关闭**：`gen_print` 默认 NULL（跟随系统默认=关），存量表零影响。
2. **从表不生成**：打印页只挂在主表/单表上（`master_table_id` 非空的表跳过）。
3. **取数前置**：主子表复用 `GET /{id}/with-children`；单表复用 `GET /{id}`（`genDetailApi`）。两者都没有时不生成打印页（开关再开也没用）。
4. **列数溢出**：明细列超过 8 列自动精简到前 8 列（isList 顺序），readme 提示。
5. **合计口径**：BigDecimal/Double 列按「分」整数求和后格式化（规避 JS 浮点误差）；Integer/Long 直接求和。前端算，不改后端接口。
6. **打印页脱离导航壳**：路由注册为无 layout 顶层路由，否则打印出来带侧边栏。
7. **孙表**：作为独立明细块平铺渲染（列取孙表 isList），数据由前端从子表 rows 里展平。

## 四、验收标准

- [ ] 基线 52 份全绿；契约 13 例全绿（`mvn -o test`）
- [ ] 开 gen_print 的主子表：产物含 `print.vue`、列表出现「打印」按钮、打印页含全部子表块与合计行
- [ ] 开关关掉：产物不含 print.vue、页面无打印按钮（真正生效）
- [ ] print-to-pdf：A4 尺寸 595×842pt、明细跨页表头重复
- [ ] console 零报错（CDP 截图）
- [ ] 预览路径集合 == 落盘路径集合（写盘类历史事故点）

## 五、歧义澄清记录

| 歧义 | 决策 |
|---|---|
| 规划写 `NOT NULL DEFAULT 0`，但系统默认开时表级永远 0 会短路回落 | 按坑库 mysql.md（V4.4 NOT NULL DEFAULT 坑）改 **NULL DEFAULT NULL 三态**：NULL=跟随系统、1=开、0=强制关 |
| 合计服务端算还是前端算 | 前端按分求和（规划§八两个选项取其一），后端接口零改动，基线/契约不扩散 |
| 系统默认 gen_print 的编辑入口 | 补进 project/index.vue 开关默认区（V4.4 的级联默认未进 UI，本版只补打印默认，级联默认 UI 缺失另记待办） |
