```markdown
## 一句话介绍
输入数据库表结构，一键生成可编译、可运行的 Spring Boot 3 + Vue3 全栈业务系统。

## 项目简介
市面上的代码生成器大多停在"生成一堆文件"，生成完能不能编译、能不能跑、以后改了表怎么办，
全都得自己兜。CodeGen 想解决的就是生成之后的这一段。

它的做法是把数据库元数据当成唯一事实来源：一份 DDL 或一个数据库连接，
同时生成后端的 Entity / Mapper / Service / Controller / DTO / VO，
以及前端的 API 封装、Vue 页面、路由和菜单。前后端读的是同一份元数据，所以不会出现
"接口改了页面没改"的漂移。

在生成之外，它把工程质量也做进了流程：

- **真实编译自检**：生成完在内存里跑 javac，编译不过直接报错，不会给你一堆跑不起来的代码
- **标记块合并**：只改自己生成的那段代码，手写逻辑原样保留，可以接管已有项目而不是只能新建
- **四态台账 + 一键回滚**：每次生成留痕，出问题可以整批退回去
- **12 步流水线**：从一句中文描述开始，自动建库、生成脚手架、生成代码、灌种子数据、注册菜单，最后跑起来
- **权限与国际化**：用户 / 角色 / 菜单权限和 206 语言框架一起生成，不是事后补

目前实际跑通的完整系统有：智慧警务（221 个控制器 / 130 个页面 / 12 个业务域）、
智慧村务（94 个控制器 / 90 个页面），以及 MES、HR、服装 ERP 等行业模板共 250+ 套。
项目自带 486 个单元测试，CI 全绿。

## 推荐理由
1. **能验证**：不是录个屏说"我行"，是给了一个能双击就跑的完整产物
2. **敢碰存量项目**：标记块合并 + 回滚台账，这个组合在同类项目里少见
3. **中文场景友好**：从表注释、字段注释直接推导中文菜单和表单标签，不用再手写一遍
4. **学习价值**：代码生成器的完整实现（元数据建模、模板引擎、增量合并、质量门禁）本身就是一个不错的工程案例

## 技术栈
Java 21 / Spring Boot 3 / MyBatis-Plus / MySQL 8 / Vue 3 / Element Plus / Vite

## 适合谁
- 需要快速搭后台的业务团队
- 想接手别人留下的老项目、又不想推倒重来的开发者
- 对代码生成器实现原理感兴趣的同学
```
