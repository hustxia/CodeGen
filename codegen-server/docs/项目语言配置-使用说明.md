# 项目语言配置 · 使用说明

> 版本 V7.5　日期 2026-11-11　适用：codegen-server + codegen-web

## 这是什么

平台此前没有任何语言配置：生成物里 `<html lang="zh-CN">`、移动端 `index.html`、模板里的中文提示全是硬编码。
V7.5 增加**项目级语言配置**：一份权威的 **206 种世界语言**清单，并让每个系统（一套输出配置）能指定默认语言与启用语言。

> 注意：这是「配置能力 + 生成物注入点」，**不是**把平台管理界面翻译成 206 种语言。
> 界面文案的逐语言翻译需要译文源，属于独立立项；本次交付的清单可以直接被后续 `vue-i18n` 复用。

## 语言清单

| 项 | 值 |
|---|---|
| 真源 | `src/main/resources/i18n/languages.json`（编译进 jar，随版本走） |
| 规模 | 206 = 188 个 ISO 639-1 + 18 个常用 BCP47 变体 |
| 数据来源 | JDK 21 CLDR（`Locale.getISOLanguages` / `getDisplayLanguage`），中文名与本地自称均取自 CLDR，非人工编造 |
| RTL 语言 | 12 种（`ar` `fa` `ur` `he` `ar-EG` `dv` `ks` `ku` `ps` `sd` `ug` `yi`） |
| 数据库镜像 | `sys_language`（**可选**，运行时不查它；没跑迁移脚本接口照常可用） |
| 关联文档 | `readme` 字段指向仓库已有的 48 个 README 译本，把文档译本与平台能力对齐 |

单条数据结构：

```json
{"code":"ar","iso6392":"ara","locale":"ar-SA","nameEn":"Arabic","nameZh":"阿拉伯语",
 "nameNative":"العربية","region":"SA","script":"Arab","dir":"rtl",
 "readme":"README_AR.md","enabled":true,"sortNo":160}
```

## 三步启用

### 1. 执行迁移（只需一次，脚本幂等）

```bash
mysql -uroot -p gen_platform < docs/sql/V7.5__language_config.sql
```

- 建 `sys_language` 并写入 206 条（`ON DUPLICATE KEY UPDATE`，重跑不翻倍）
- `sys_project` 追加 `default_language` / `supported_languages` 两列（`information_schema` + `PREPARE` 条件加列，重跑不报 1060）
- 两列都可空，**存量系统零 diff**：空 = 回落 `zh-CN` / 全部启用

> 不执行也能用：`/language/*` 接口从 classpath JSON 读，不查库。只有需要 SQL 侧查语言清单时才必须执行。

### 2. 在系统配置里选语言

`系统管理 → 编辑系统`：

- **默认语言**：下拉 206 项，可输入过滤，值为 BCP47 标签（如 `ar-SA`）。生成物 `<html lang>` 取此值。
- **启用语言**：多选，值为语言码（如 `zh,en,ar,ja`），留空 = 全部启用。

保存后刷新会回显。选了 RTL 语言，生成物的 `<html>` 自动带 `dir="rtl"`；代码块、路径仍保持 LTR。

### 3. 生成时的效果

| 配置 | 生成物 `public/index.html` |
|---|---|
| 未配置（存量系统） | `<html lang="zh-CN">` —— 与改造前**完全一致** |
| `defaultLanguage = en-US` | `<html lang="en-US">` |
| `defaultLanguage = ar-SA` | `<html lang="ar-SA" dir="rtl">` |

模板渲染模型新增 `lang` / `dir` 两个键，`.ftl` 模板可直接用 `${lang}` / `${dir}`。
移动端工程（`scaffold-mobile/index.html`）通过 `__HTML_LANG__` / `__HTML_DIR_ATTR__` 占位符注入同样的值。

## 接口

前端路径**不带** `/api`（dev 代理 `/dev-api` 会去前缀）。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/language/list` | 全量 206 条 |
| GET | `/language/list?dir=rtl` | 12 条 RTL 语言 |
| GET | `/language/options` | 下拉选项 `{label,value,dir,script,code}`，`label` 为「中文名（本地自称）」 |
| GET | `/language/{code}` | 单个语言；不存在返回 `code=500` + 提示 |
| GET | `/language/default` | 默认语言与清单规模 |

## 回落与边界

| 场景 | 行为 |
|---|---|
| 未配置 / 空串 / 空白 | 回落 `zh-CN`，`dir=ltr` |
| 大小写 / 下划线写法 | `ZH_CN`、`zh-cn` 等价于 `zh-CN` |
| 传两字母码 `ar` | 展开为默认地区标签 `ar-SA` |
| 清单外的合法标签 | 原样保留（不因未收录就强制改中文） |
| 非法标签（含引号、`<script>`） | 回落 `zh-CN`，避免打坏生成物 HTML |
| JSON 缺失 / 损坏 | 降级为最小清单 `zh-CN` / `en-US`，打 warn 不阻断启动 |

**单一实现原则**：归一、回落、BCP47 解析、dir 判定、HTML 属性合法性校验全部只在
`com.codegen.config.LanguageConfig` 里实现。模板、脚手架、前端都不许再写一遍。

## 扩展语言清单

1. 改 `D:/workspace/github/gen_languages.java`（生成器，用 JDK 21 CLDR，不手工编造译名）
2. 运行 `java gen_languages.java` 重新产出 JSON 与 SQL
3. 三处同步检查：实体（`SysProject.java`）、交付脚本（`docs/sql/V7.5__*.sql`）、测试库（`src/test/resources/schema-test.sql`）
4. 跑 `mvn -o test` 全量回归
